临时区

全部干员摘选区：左键 = 以「扩展」方式放入临时区（并入后新行条件/备注为空）。
条件＝硬性达成条件（精英化／技能／专精／模组与等级／模式限定／目标限制），精零 1 级即具备写「无」；备注＝加工后的信息（数值、持续时间、隐藏机制、用法）。单元格须单行、不含竖线 |；保存后并入名单文档，即最终 JSON 的 condition / remark。

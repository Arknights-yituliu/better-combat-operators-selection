# 初动

## 判定口径

- 纳入：**本干员机制**（本体 + 天赋 + 技能 + 模组 + 召唤物/装置）能够为**其他干员**在**开局/部署时点一次性增加技力（含原文“初始技力”）**的干员（spec：「类似风笛、凛御银灰等一众可使干员初始技力增加的干员」）。硬性条件写入「条件」列（精英化、模组及等级、职业/阵营/位置限制、是否需在场、是否编入队伍即生效）；增加方式（编入队伍/部署时/其他触发）与具体数值写入「备注」。
- 与「充电」的分工：**初动＝开局/部署时点的一次性技力给予**；**充电＝持续回复速度/回复量，或击杀·受击·攻击·治疗等触发回复**（不属本 TAG，互链 `03-充电.md`）。此分工与 `03-充电.md` 判定口径中「仅提供初始技力/部署时技力者已独立为初动 TAG」互为对应。
- 模式限定模组（ISW-α / RA-α / SO-α 等）若因此获得为他人提供初始技力的能力则计入并写明模式限定；**本批无此类成员**（模式限定模组中的技力效果均为自身，见排除记录）。
- 排除：仅自身的初始/部署时技力；击杀触发、概率触发；费用类；再部署时间类；只对召唤物/装置生效的；非技力资源（魔力/金币）且不能转化为他人技力的。
- 数值取 PRTS 原文关键档位（专三/7级/模组等级/精英阶段），潜能为数值档位写入备注（如「潜能5后+N」）。

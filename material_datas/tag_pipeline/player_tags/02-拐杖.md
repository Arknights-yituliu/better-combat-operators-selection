# 拐杖

## 评定标准

- 依据 specify 原文：「类似白铁1、娜斯提3（仅限高台）、华法琳2、阿3、号角2天赋（仅限重装）等**有条件或无条件能够给其他干员直接增加攻击力或攻击速度**的干员」。号角天赋编号以 PRTS 为准（「军事要塞」= 第一天赋，规格文档已修正）。
- **纳入**：通过天赋/技能/模组/召唤物/装置/光环，为**其他干员**（含目标包含自身的"自身和目标"类）直接增加**攻击力**或**攻击速度**；含"鼓舞"中提供攻击力的部分；含"拐亦是被拐者"型（如阿、能天使）。
- **排除**：脆弱/易伤（受伤提升）、减防/削抗/法穿、纯技力回复（属「充电」）、纯生存保护（属「保人」）、部署费用/初始技力类、攻速"下限覆写"（属「抗削弱」）、仅自身增益、对敌减攻速、**从友方偷取**攻速（新约能天使2技能）。
- **多 TAG 允许重复**（开发者评定标准）：同一干员可同时属于「拐杖」「充电」「保人」「阵容组合」等；仅因归类他 TAG 而排除者，只要满足本 TAG 判定即重新纳入（本轮据此补入 凛冬、推进之王）。
- **召唤物/装置效果计入持有干员**（白铁装置、娜斯提高台装置、掠风可靠电池）。
- **模式限定模组（ISW-α/RA-α 等）计入**，在条件中写明模式限定、备注注明仅该模式可用（见空弦）。
- 攻速"下限覆写"与"上限提升"类"保局内机制下限/上限"能力，按开发者评定标准归入新 TAG **「抗削弱」**，不在本表（见边界记录）。

### 子 TAG 定义

成员表「子 TAG」列由 **增益类型 + 生效方式** 两组子 TAG 组成，多值用「、」分隔。

| 组 | 子 TAG | 含义 |
|---|---|---|
| 增益类型 | `攻击力(加算)` | 提升面板攻击力的加成（+X%攻击力，含鼓舞、精力充沛） |
| 增益类型 | `攻击力(倍率)` | "攻击力提升至X%"型，仅作用于本次伤害的攻击力乘区、不加算面板（如摆渡人） |
| 增益类型 | `攻击速度` | 直接提升攻击速度（含攻速+N） |
| 生效方式 | `在场` | 需该干员在场上 |
| 生效方式 | `编入` | 编入队伍即可，无需在场上 |
| 生效方式 | `携带` | 携带即可，无需在场上 |
| 生效方式 | `部署时` | 部署时/部署后一次性触发 |
| 生效方式 | `技能开启时` | 开启技能时触发 |
| 生效方式 | `技能期间` | 技能持续期间生效 |
| 生效方式 | `触发时` | 由治疗、击倒敌人、装置升级等行为条件触发 |

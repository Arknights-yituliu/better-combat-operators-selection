# 插拔容错 · 路径②子类「既定位置直部署型」全库扫描

> 只读全库扫描草稿，供主协调者把该子类并入 `05-插拔容错.md` / `docs/player-tags-specify.md` 时取用。判定一律以 `material_datas/PRTS/` 原文为准，行号真实可查。全库 431 名干员 + 501 个召唤物文件。

## 扫描口径（本次采用的评定标准）

- **①自动/指定位置部署**：非正常手动部署——机制自动从待部署区把单位送到「既定位置」（如艾丽妮的「原位置」），或机制使单位可直接投放到指定位置。
- **②立即开启技能**：部署即开启技能 / 技能随部署随即生效。
- **③救急职能**：群控 / 群伤 / 单切 / 治疗 / 减伤 / 回费之一。
- **④模式限定**：ISW-α / RA-α / SO-α 等特限模组的效果计入，条件写明模式限定（依据 `_brief.md` §2.3）。
- 场内**【移动】**（本体须先正常部署、技能开启后才位移）不属「从待部署区部署至既定位置」，一律列入排除。

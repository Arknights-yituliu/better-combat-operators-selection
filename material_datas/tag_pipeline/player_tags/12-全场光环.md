# 全场光环

## 判定口径

- 依据 specify 原文：「类似塑心Y模组（全场敌人受到凋亡损伤提高、爆发期间持续元素伤害）、安洁莉娜ISW-α（全场失衡/浮空敌人持续受到法术伤害）、莫斯提马2天赋等以"整个战场"为范围持续生效的光环类效果。区分子TAG：增伤光环、伤害光环、削弱光环等；如果某个干员的光环有硬性条件，则写在条件里，效果与数值写在备注里。」
- **纳入**：以**整个战场**为生效范围、**持续生效**的光环/领域类效果。纳入线沿用本项目「远程消耗」已确立的关键词口径（`docs/judge-for-player-tags-members.md:49`）并扩展：**原文出现「全场 / 全地图 / 整个战场」，或天赋/模组中以「所有友方单位 / 敌方单位 / 场上敌人（无"攻击范围内/周围X格"前缀）」描述且无距离限制**的效果。含**触发式**全场效应（触发条件写入「条件」列，依据开发者对"全场触发式"的放宽裁决 `docs/judge-for-player-tags-members.md:54`）；含**模式限定模组**（ISW-α / RA-α 等，条件写明模式限定、备注注明仅该模式可用）。
- **子 TAG（方向）**：
  - `增伤光环`＝使全场敌人**受到的伤害/损伤提高**（脆弱、损伤易伤等），不造成伤害本身；
  - `伤害光环`＝**全场范围内持续/周期/触发式造成伤害**，不依赖自身射程与攻击行为；
  - `削弱光环`＝全场降低敌人属性（攻速/移速/重量/抗性）；
  - `增益光环`＝全场友方属性提升（仅收**原文写「全场/全地图」或无职业·阵营限定的「所有友方单位」**者）；
  - `治疗光环`＝全场友方持续回复（生命/元素损伤）。
- **排除**：① 仅在攻击范围/周围X格内生效的**范围光环**（铃兰脆弱、浊心斯卡蒂、塞雷娅、夜半、娜斯提装置等）；② 一次性全场结算（部署时救援喷雾、金币弹幕、15秒浮空等）；③ 全图打击手段（归「远程消耗」/官方 H_fullmap：安比尔、澄闪、荒芜拉普兰德、蕾缪安、提丰）；④ 自身增益（妮芙 X模组）；⑤ 召唤物自身范围光环（除明确作用于全场）；⑥ 技力回复类全场光环（归「充电」，见边界记录）。
- 同一干员可同时属多个子 TAG（如 安洁莉娜 同时为伤害/削弱/增益/治疗光环），故在多个子表重复出现；数值取 PRTS 原文关键档位，潜能为附加档写入备注。

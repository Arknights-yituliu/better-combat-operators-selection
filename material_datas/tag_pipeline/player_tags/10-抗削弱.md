# 抗削弱

## 评定标准

- 规格原文：「类似信仰搅拌机X模组3级（使场上所有【拉特兰】干员的攻击速度不会低于战斗开始时的攻击速度）、可露希尔2天赋（降低部署费用下限，可透支部署）等能够保『局内默认机制下限』和提高『局内默认机制上限』的干员」。
- **纳入**：能力须由 PRTS 原文明确指向**其他干员/全队/局内机制**（「场上所有【拉特兰】干员」「其他拉特兰干员」「携带…时」等），语义为「下限被守住/抬高」「上限被提高」或「为他人降低/免除资源消耗」，含为其他干员/全队提供抵抗与净化。
- **排除**：单纯数值增益（+攻击/+攻速，归 08-拐杖.md）；伤害减免/庇护/屏障/锁血/不死（归 09-保人.md）；免疫类（官方 C 类 TAG）；仅自身的资源上限提高与数值成长（自身弹药上限、金币上限、魔力上限、召唤物持有上限、浮游单元伤害上限等）；只改写某次部署事件费用结算的效果（费用交换、该次部署免费、状态型费用×0）；无法用原文证实的推测机制。
- **与其它 TAG 的关系**：补弹（为他人弹药类技能装填弹药）归 07-充电.md；攻击/攻速等纯增益归 08-拐杖.md；减免、屏障、免死等保护归 09-保人.md；「抵抗」「净化（解除异常）」的官方 TAG 记录的是拥有该状态/能力者（含仅自身），本 TAG 的「负面状态防护」只收**可为其他干员/全队提供**抵抗或净化者，两者范围不同、可同时成立。
- **子 TAG**：
  - **下限保护**：为其他干员/全队覆写或守住某项机制的下限（攻速下限、费用下限、其他机制下限），含使其他干员的资源消耗数值降低或免除（部署费用降低、弹药概率不消耗）；仅自身的伤害/治疗保底亦收录，并标注作用范围。
  - **上限提高**：为其他干员/全队提高某项机制的上限（弹药上限、技力上限、费用可及范围——如「可透支部署」使当前费用可为负）。
  - **负面状态防护**：抵抗＝为其他干员/全队提供「抵抗」（可抵抗状态持续时间减半）；净化＝解除其他干员所受的异常状态。
- **作用范围**：对他人（缺省，不标注）/ 全队 / 仅自身；行内写作 `下限保护 + 作用范围/仅自身`。
- **约定**：
  - 数值取 PRTS 关键档位（技能取专精3、模组注明等级），潜能档位写入备注；非 PRTS 原文直引的数值与推算值标注「（待验证）」。
  - 条件写硬性前提（精英化、模组及等级、目标限制、在场/编队、触发前提），备注写机制、数值、触发方式与限制。
  - 模式限定模组（ISW-α/RA-α 等）与模式限定天赋计入，条件写明模式；召唤物/装置计入持有干员。

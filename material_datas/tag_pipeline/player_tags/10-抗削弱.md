# 抗削弱

## 评定标准

- 规格原文：「类似信仰搅拌机X模组3级（使场上所有【拉特兰】干员的攻击速度不会低于战斗开始时的攻击速度）、可露希尔2天赋（降低部署费用下限，可透支部署）等能够保『局内默认机制下限』和提高『局内默认机制上限』的干员」。
- **纳入**：能力须由 PRTS 原文明确指向**其他干员/全队/局内机制**（「场上所有【拉特兰】干员」「其他拉特兰干员」「携带…时」等），且语义为「下限被守住/抬高」或「上限被提高」（不低于 / 下限降低 / 上限+N），而非单纯数值增益或消耗减免。
- **子 TAG**：**下限保护**＝为其他干员/全队覆写或守住某项机制的下限（攻速下限、费用下限、其他机制下限）；**上限提高**＝为其他干员提高某项机制的上限（弹药上限、技力上限等）。同一干员按其能力归入对应子表。
- **排除**：单纯数值增益（+攻击/+攻速，属拐杖）、伤害减免/庇护/锁血/不死（属保人）、免疫与抵抗（官方 C 类 TAG）、仅自身的上限提高或仅自身保底（列入边界并注明）、无法用原文证实的推测机制；「生命值不低于1」等生存下限**一律归保人**，不因字面「不低于」重复收录。
- **约定**：模式限定模组（ISW-α/RA-α 等）计入——但全量特限干员的模式限定效果均为自身或召唤物向（琳琅诗怀雅 ISW-α 金币上限+5、归溟幽灵鲨 ISW-α、百炼嘉维尔 RA-α、凯尔希 ISW-α Mon3tr 强化、森蚺/水月/提丰/异客/电弧/机械师/夕/傀影/艾丽妮/空弦/菲亚梅塔/霍尔海雅/安洁莉娜/佩佩/灵知/迷迭香等），无一为对他人/全队的下限保护或上限提高，故主表无模式限定成员（见边界）；条件写硬性前提（精英化、模组及等级、目标限制、在场/编队、触发前提），备注写保护/提高的具体机制、数值、触发方式与限制，数值取 PRTS 关键档位（专三/模组等级），潜能档位写入备注。

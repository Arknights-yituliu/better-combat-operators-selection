# 保人

## 评定标准

规格原文：「类似夜莺（法伤减免）、年3（物伤减免、阻挡增加）、纯烬艾雅法拉（元素损伤减免）、焰尾2（物理闪避）等能够为其他干员提供保护的干员。如果某个干员的保护能力有硬性条件，则写在条件里……对于具体保人的数值，写在备注里。」

- **纳入（对友方，含召唤物/装置来源）**：**为友方提升受到的治疗效果**、伤害减免（比例庇护/数值减伤/伤害转移承担）、防御力或法抗提升、闪避/抵挡给友方、屏障/护盾给友方、免死/锁血/不死给友方、元素损伤治疗·损伤减免·损伤屏障、嘲讽/吸引火力/为他人转移仇恨、使友方不被选为目标（迷彩类）、**弹道拦截**（使敌方弹道降速、停止或清除）。
- **排除**：纯回血/纯群奶（不带减免/屏障/护盾等附加保护者不收）；仅自身的减伤/闪避/屏障/护盾/锁血/替身；单独的“阻挡数增加”（归 13-高档控制.md「阻挡数5」，仅在因其他保护入表时写入备注）；明确对敌的效果；抵抗/净化等负面状态防护（含对他人与仅自身）归官方设定 TAG「抗削弱」，本 TAG 不收。
- **与其它 TAG 的关系**：抵抗/净化（负面状态防护）归官方设定 TAG「抗削弱」；「阻挡数增加」归 13-高档控制.md「阻挡数5」；允许同一干员同属多个玩家 TAG（如 塑心、黍 亦可归 08-拐杖.md），不因已归其他 TAG 或定位偏拐而排除满足上述保护判定者。
- **子 TAG**：治疗·减免·防御·法抗·庇护（含为友方提升受到的治疗效果、数值减伤与弹道拦截）/ 屏障·护盾（含物理护盾）/ 闪避·迷彩（规避与不被选为目标）/ 元素损伤防护（行医系·损伤屏障·损伤减免）/ 免死·锁血·伤害转移 / 嘲讽·吸引火力·指定承伤（含召唤物）。
- **约定**：**取档**：模组按对本 TAG 有帮助的最高档取用（按绝对贡献判，不得因更高档拉低比值／稀释均值而改取低档；持特限证章者：通用线与特限线**分别计算**、UI 分别展示且**特限线优先展示**（细则见 `docs/ui-render-rules.md`）、无特限证章者默认各模组增伤条件均满足并取更高者）并把所选档写进条件；**嘲讽位／承伤位自身的硬度算「对本 TAG 有帮助」**（该位站得越久、吸火越久），故其模组的减伤、屏障、闪避与固定生命／防御加成均在取档范围内（例：泡泡、斥罪、玛恩纳、若叶睦、阿斯卡纶、麒麟R夜刀、车尔尼、老鲤 取各自 X／Y 线最高档）；**受生命值影响的伤害转移也算「自身变硬」**（如 浊心斯卡蒂 的生命流失转移——转移量随生命上限走，故其模组档位写进条件）；转移本身不改变承伤窗口长短者不计（如 斩业星熊 临死模式持有不死、窗口固定 11 秒，其模组档位不因此计入）。
  - 方向判定：一切以 PRTS 原文主语/宾语为准（“使周围友方干员…”“治疗的目标获得…”为对友方；“自身获得…”为仅自身）。
  - 防御/法抗提升按“体感物/法伤减免”收，并在备注注明是防御/法抗加成；小幅度/临时型（星熊、嘉维尔、Castle-3）同样纳入，写清数值与持续时间。
  - 数值标准：技能取 Rank Ⅲ（专精3），天赋取最高等级并随文注明精英阶段，模组效果注明模组等级；推算值（攻速／间隔换算或倍率相乘）按既定规则直接给出（不再另加标记）；原文数值的单步加减与倍数换算不标。
  - 召唤物/装置计入持有干员（鸟笼幻影、机动盾牌、造型仪、防护单元、夜灯、质检/监工专员、机械水獭、诅咒娃娃等）。
  - 模式限定模组（ISW-α/RA-α）同样计入——条件中注明模式限定、备注注明仅该模式可用（如 归溟幽灵鲨 ISW-α3）。

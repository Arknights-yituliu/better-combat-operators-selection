## 三、系统性发现汇总

### S1 模组档位固定属性（攻击＋N）—— 全组一致未计入，但 TAG 未写明
本组 22 条的**档位固定攻击**一律不折入倍率：妮芙 X模组3级 攻击＋80（`妮芙/妮芙.md:240`）、维什戴尔 ＋65（`:253`）、锏 X ＋50／Y ＋80（`锏/锏.md:234,359`）、赫德雷 Y ＋160（`:350`）、隐现 X ＋38（`:221`）、麒麟R夜刀 X ＋48（`:238`）、伺夜 ＋25/＋30（`:246,374`）、百炼嘉维尔 X ＋73（`:267`）、鸿雪 Y ＋75（`:379`）、艾丽妮 X ＋50/Y ＋50（`:225,352`）、归溟幽灵鲨 ISW-α ＋40（`:451`）、号角 X ＋100（`:228`）、洛洛 X ＋18（`:194`）、令 Y ＋50（`:245`）、导火索 CEN-Y ＋70（导火索/导火索.md:220）。
**而档位固定攻速一律计入**（R2 明文，如 妮芙＋12／维什戴尔＋7／百炼嘉维尔＋100）；麦哲伦行（`03-吃拐一轮秒.md:83`）还明写「无人机伤害提高，上列倍率按各自攻击力计不变」。
→ **建议**：在 `03-吃拐一轮秒.md` 的 约定 补一句口径——倍率以 R7 的 E2 满级面板为基准、模组档位固定攻击不计入（否则须一律改写为 `×(面板＋N)÷面板`）。目前全组做法一致，故本审计按「不计」判定，无一计入者。

### S2 「同层相加」只适用于直接乘算池；最终乘算层按官方算例为独立相乘
`_rules/作战机制.md:401-406` 官方两式：直接乘算 `X2＝X1(1＋b1%＋b2%)`（同池相加）、最终乘算 `X4＝X3×d1%×d2%`（各因子独立相乘）；`_rules/游戏数据基础／属性计算例子.md:41` 算例 `1000×(1−40%＋200%)×60%＝1560` 亦同。
本组 22 条**没有一处**在本应相加的直接乘算池里连乘；同时两处**两个「提升至」因子相乘**的写法（鸿雪 `255%×1.05`、锏 X模组 `1.70×1.10`）符合官方 X4 式，故 `placement_ok` 全为 true。
→ **建议**：任务书 B 项的「同层相加」应明确限定为**直接乘算池**；最终乘算层（多个「提升至X%」「造成的伤害提升X%」并存时）按官方算例为独立相乘，避免后续把 `255%×105%` 误改为 `255%＋5%`。

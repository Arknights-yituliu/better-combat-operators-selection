## 3. 作业规范（子代理必读）

### 3.1 红线

1. 只处理数值与「（待验证）」标记；**不得**增删成员行、改条件、「依据」列、名单判定；**不得**改写句序、合并/拆分句子、改能力名（备注只做最小片段替换）。
2. 不写「本轮/已更新/修正后」类过程语；不写「更佳/可选」类模糊措辞。
3. 拿不准的不硬判：给出两套算法与 `pending_rule`（C1…C5），交由开发者裁定。
4. 量纲与小数位随原值：% 到 0.1%、秒 2 位、× 2 位；整数单位（下/发/段/枚/次/轮/跳）取整并给算式。

### 3.2 证据

- 一切数值落到 `material_datas/PRTS/` 下的 `文件:行号`（相对 `material_datas/PRTS/`，如 `结城理/结城理.md:64`）；行号**逐页定位**、不得跨页套用；优先复用条目「依据」列已有行号，新引行号须在 `evidence` 里说明用途。
- 属性表取值必须**按表头定位列**（「精英2 满级」列），不得硬编码列下标；攻击间隔行形如 `| 阻挡数 | N | 攻击间隔 | X.XXs |`。
- 技能/天赋数值在同页 `## 技能`／`## 天赋`／`## 模组` 段；模组数值行多字段连写、按内容切分。

### 3.3 输出（写 `parts/<组>.jsonl`）

在输入条目全部键的基础上**追加**以下键（一个 id 一行，顺序与输入一致）：

```json
{
  "evidence": [{"src": "结城理/结城理.md:15,17,35,62,64", "use": "特性持续/攻击间隔/攻速/攻击力加成/面板"}],
  "inputs":  [{"item": "面板攻击力", "value": "687", "src": "结城理/结城理.md:64"}],
  "steps":   [{"expr": "15÷1.0", "round": "none", "value": 15, "note": "15 秒窗口攻击次数"},
              {"expr": "15×2.30×1.95", "round": "round", "value": 67.275, "note": "总倍率（比值）"}],
  "recomputed_value": "6728%",
  "conclusion": "一致",
  "delta": null,
  "pending_rule": null,
  "impact": null,
  "new_fragment": "6728%",
  "new_remark_expected": "<raw_note 用 旧片段→新片段 替换后的全文>",
  "notes": ""
}
```

字段语义：

- `steps`：逐步计算。`expr` 用 `× ÷ ＋ － ( )` 与数字（`%`＝除以 100，如 `230%`＝2.3；不得含 `≈ → ⌊ ⌋` 等符号）；`round` ∈ `none|round|floor|ceil`（`round`＝四舍五入到整数）；`value`＝应用 `round` 后的结果（与 expr 同量纲）。
- `recomputed_value`：展示值（带单位，如 `6728%` / `1.03 秒` / `15 枚`），与最后一步对应（比值 ×100 得 %）。
- `conclusion`：`一致`｜`不一致`｜`待裁定`；`delta`＝`{"from":"…","to":"…"}`（不一致时必填）。
- `impact`：`{"text":"门槛 ≥3000%，仍达标","pass_before":true,"pass_after":true}` 或 `null`（未跨门槛）；跨门槛/翻转必须写。
- `new_fragment`：替换 `old_fragment` 的最终文本（去标记；值有修正则写修正后片段）；`new_remark_expected`＝`raw_note` 应用该替换后的全文（供最小 diff 校验：**除数字 token 与标记外不得有其它差异**）。
- `notes`：不确定点、需人工确认处（无则 `""`）。

### 3.4 排版与用词

- 计算式一律显式写取整步骤（如 `15÷2.13≈7.04→7 下（四舍五入）`）。
- 数值来源在 `inputs` 里逐一注明 `src`；正文表述沿用原备注的文风（不加书签式标注）。

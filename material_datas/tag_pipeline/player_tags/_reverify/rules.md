## 3. 作业规范（子代理必读）

### 3.1 红线

1. 只处理数值与「（待验证）」标记；不得增删成员行、改「依据」列、名单判定；**改条件仅限 R19 的「多模组取最高档写进条件」一类，经 `cond_edits` 声明**；不得改写句序、合并/拆分句子、改能力名（备注只做最小片段替换）。
2. 不写「本轮/已更新/修正后」类过程语；不写「更佳/可选」类模糊措辞。
3. 拿不准的不硬判：给出两套算法与 `pending_rule`（登记未决项），交由开发者裁定。
4. 量纲与小数位随原值：% 到 0.1%、秒 2 位、× 2 位；整数单位（下/发/段/枚/次/轮/跳）取整并给算式。
5. **「待裁定」标注纪律**：`conclusion=待裁定` 与 `pending_rule` 只用于**实际计算过程中切实存在的歧义**；仅因模组/潜能等数值提升而不同于原值的，直接按确认（不一致）处理、不标「待裁定」。可选扩充项（如未决的附加伤害候选）记录在 audit 的候选节，不阻塞条目的确认。
6. **自立文本**：产出链（成员行条件/备注、替换对、notes/potential_note）一律**自包含**——不得出现条目 id、其它分文件名、「见/另见/同上/同 -N/同格 -N/同干员另一条」类指称；同格重复内容也要各写全；TAG 名可作归属标签但须自带数值。豁免：`docs/*.md` 规范指针（评定标准/约定段）与 PRTS `文件:行号` 证据位。

### 3.2 证据

- 一切数值落到 `material_datas/PRTS/` 下的 `文件:行号`（相对 `material_datas/PRTS/`，如 `结城理/结城理.md:64`）；行号**逐页定位**、不得跨页套用；优先复用条目「依据」列已有行号，新引行号须在 `evidence` 里说明用途。
- 属性表取值必须**按表头定位列**（「精英2 满级」列），不得硬编码列下标；攻击间隔行形如 `| 阻挡数 | N | 攻击间隔 | X.XXs |`。
- 技能/天赋数值在同页 `## 技能`／`## 天赋`／`## 模组` 段；模组数值行多字段连写、按内容切分。


字段语义：

- `steps`：逐步计算。`expr` 用 `× ÷ ＋ － ( )` 与数字（`%`＝除以 100，如 `230%`＝2.3；不得含 `≈ → ⌊ ⌋` 等符号）；`round` ∈ `none|round|floor|ceil`（`round`＝四舍五入到整数）；`value`＝应用 `round` 后的结果（与 expr 同量纲）。
- `recomputed_value`：展示值（带单位，如 `6728%` / `1.03 秒` / `15 枚`），与最后一步对应（比值 ×100 得 %）。
- `conclusion`：`一致`｜`不一致`｜`待裁定`；`delta`＝`{"from":"…","to":"…"}`（不一致时必填）。
- `impact`：`{"text":"门槛 ≥3000%，仍达标","pass_before":true,"pass_after":true}` 或 `null`（未跨门槛）；跨门槛/翻转必须写。
- `new_fragment`：对 1 的最终替换文本（替换 `old_fragment`；去标记；值有更正时写更正后的文本）。
- `extra_edits`（可选）：附加替换对（面板数字、绝对伤害等）；每对 `old` 在 `raw_note` 唯一命中、各对区间互不重叠、任何 `new` 不得包含其它对的 `old`；应用顺序＝按 `old` 在 `raw_note` 中出现的先后；同一条目替换对总计 ≤4。
- `cond_edits`／`cond_new_expected`（可选）：条件列改写（仅 R19 情形）；`old` 在 `raw_cond` 唯一命中，`cond_new_expected`＝`raw_cond` 应用该改写后的全文。
- `new_remark_expected`＝`raw_note` 依序应用全部替换对后的全文（供最小 diff 校验：**除数字 token 与标记外不得有其它差异**）。
- `potential_note`（可选）：潜能加成的计入说明（面板攻击已按 R7 并入基准，不再列「备选」；其它属性加成写明是否计入及理由）。
- `notes`：不确定点、需人工确认处（无则 `""`）。

**整数帧写法（R4）**：实际间隔步拆为两步——`{"expr":"2.1×100÷145×30","round":"round","value":43,"note":"实际间隔帧数（43.448→43 帧，四舍五入）"}` ＋ `{"expr":"43÷30","round":"none","value":1.433333,"note":"整帧实际间隔＝43/30≈1.433 秒"}`；下游计数统一写 `持续×30÷帧数`（如 `15×30÷23`），与帧数步严格同源。

**成绩项与双档（R7／R24）**：决战歼灭条目的 `new_remark_expected` 须含「15 秒总伤＋平均 DPS」；次数对策条目须含「等效每秒段数」；条件允许的精英化阶段低于最高档、且成绩依赖面板者，按「最低可满足档／最高档」两套成绩并列于备注开头。

### 3.4 排版与用词

- 计算式一律显式写取整步骤（如 `15÷2.13≈7.04→7 下（四舍五入）`）。
- 数值来源在 `inputs` 里逐一注明 `src`；正文表述沿用原备注的文风（不加书签式标注）。

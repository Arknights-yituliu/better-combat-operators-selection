# 初动增加

## 评定标准

- **纳入**：**本干员机制**（本体 + 天赋 + 技能 + 模组 + 召唤物/装置）能够为**其他干员**在**开局/部署时点一次性增加技力**的干员，含原文写作「初始技力」者（规格原文：「类似风笛、凛御银灰等一众可使干员初始技力增加的干员」）。
- **排除**：**非部署时点**的技力给予——①持续回复（技力光环、装置持续给予等）；②触发式回复（击杀触发、概率触发、治疗触发、受击触发等）；③技能期间/技能结束时的非部署时点一次性给予（本人技能结束时回复自身技力等自回类）——一律归 `07-充电.md`；仅自身的初始/部署时技力；费用类；再部署时间类；只对召唤物/装置生效的；非技力资源与特殊技力机制（琳琅诗怀雅「金币」、玛露西尔「魔力」属特殊机制，不计入）。技能期间发生的**部署时点**给予（投送、流形特殊部署）按部署时点计入本 TAG。
- **与「充电」的关系**：`07-充电.md`＝为他人**持续回复／触发式回复**技力（含技力光环与装置持续给予〔黍、白面鸮、陈、白铁、娜斯提 等〕、技能期间/技能结束时等非部署时点的给予）；本 TAG＝**开局/部署时点的一次性给予**。仅能提供初始技力/部署时技力者（风笛、凛御银灰、荒芜拉普兰德、炎狱炎熔、新约能天使、缪尔赛思）不属充电；触发式给予技力者（嵯峨/矩/罗小黑/遥/华法琳/推进之王/森西）不属本 TAG，只在充电主表收录。
- **约定**：数值取 PRTS 原文关键档位（专三/7级/模组等级/精英阶段），潜能为数值档位写入备注（如「潜能5后+N」）；硬性条件（精英化、模组及等级、职业/阵营/位置限制、是否需在场、是否编入队伍即生效、给予时点）写入「条件」，给予方式（编入队伍/部署时/特殊部署）与具体数值写入「备注」；模式限定模组（ISW-α/RA-α/SO-α 等）若提供为他人初始技力的能力则计入并写明模式限定——本 TAG 无此类成员（模式限定模组中的技力效果均为自身，见排除记录）。

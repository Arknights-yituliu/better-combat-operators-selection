# 拐杖

## 评定标准

- 规格原文：「类似白铁1、娜斯提3（仅限高台）、华法琳2、阿3、号角2天赋（仅限重装）等**有条件或无条件能够给其他干员直接增加攻击力或攻击速度**的干员」。号角天赋编号以 PRTS 为准（「军事要塞」= 第一天赋）。
- **纳入**：四类。①通过天赋/技能/模组/召唤物/装置/光环，为**其他干员**（含目标包含自身的"自身和目标"类）直接增加**攻击力**或**攻击速度**；含"鼓舞"中提供攻击力的部分；含"拐亦是被拐者"型（如阿、能天使）。②使**敌方受到的伤害提升**的脆弱/易伤，含物理脆弱/法术脆弱/元素脆弱，以及"附近所有敌军受到的法术伤害+55%"「受到的法术伤害提高150点」一类**无"脆弱"字样、语义等同**的受伤提升。③以命中/状态/阻挡为条件的敌方受伤提升（"被阻挡的敌人受到的法术伤害提升"等），状态只是生效条件，不因条件收窄而排除。④为**友方输出**增伤——既不改友方面板，也不改敌方受伤：`伤害提升(友方)`，提升友方**造成的伤害**（含「造成的X伤害提升」与按目标状态增伤等写法）；`附加伤害(友方)`，为友方的攻击附带一段由本干员结算的额外伤害（如塑心2技能附带于友方伤害的凋亡损伤）。
- **排除**：减防/削抗/法穿、纯技力回复（属「充电」）、纯生存保护（属「保人」）、部署费用/初始技力类、攻速"下限覆写"（属「抗削弱」）、仅自身增益、对敌减攻速/虚弱（敌攻击力降低）、**只放大该干员自身伤害**的"对其造成的伤害提升"、**提高敌方元素损伤累积**（`受到的X损伤提高`）而非受到的伤害、**从友方偷取**攻速（新约能天使2技能）。
- **与其它 TAG 的关系**：同一干员可同时属于「拐杖」「充电」「保人」「阵容组合」等；仅因归类其他 TAG 而排除者，只要满足本 TAG 判定即纳入（如 凛冬、推进之王）；敌方受伤提升类与官方设定 TAG「施加脆弱（易伤）」同向，官方列表的取舍不影响本表判定（见边界记录）。
- **与「抗削弱」的关系**：攻速「下限覆写」与「上限提升」类保局内机制下限/上限的能力属 **「抗削弱」**，不在本表（见边界记录）。
- **约定**：数值取 PRTS 关键档位（专三/模组等级）；召唤物/装置效果计入持有干员（白铁装置、娜斯提高台装置、掠风可靠电池）；模式限定模组（ISW-α/RA-α 等）计入，条件写明模式限定、备注注明仅该模式可用（如 空弦、森蚺）；易伤类按 PRTS 明文数值记录，固定值（如「+150 点」）与比例分别注明；受伤提升只对特定伤害类型（物理/法术/元素）或特定目标（空中单位、被阻挡、低血线等）生效者，条件与备注写明该限制；备注中的推算值（攻速／间隔换算或倍率相乘、叠乘）按既定规则直接给出（不再另加标记）；原文数值的单步加减与倍数换算不标。**取档**：模组按对本 TAG 有帮助的最高档取用（按绝对贡献判，不得因更高档拉低比值／稀释均值而改取低档）、所选档写进条件；持特限证章者：通用线与特限线**分别计算**、UI 分别展示且**特限线优先展示**（细则见 `docs/ui-render-rules.md`）、无特限证章者默认各模组增伤条件均满足并取更高者；若该模组的增益会随「第二天赋效果提升」之类的能力同步放大（如 塑心 3技能 2.5 倍放大元素脆弱），按放大后的数值比较取档。

### 子 TAG 定义

成员表「子 TAG」列由 **增益类型 + 生效方式** 两组子 TAG 组成，两组值分别按 `组/值` 书写，多条用「、」连接（例：`增益类型/攻击力(加算)、生效方式/技能开启时`）。`触发时` 须并记 detail，写作 `生效方式/触发时(造成治疗时)`。

**增益类型**（该干员对外提供的增益形态，可多值并存）

| 组 | 子 TAG | 含义 |
|---|---|---|
| 增益类型 | `攻击力(加算)` | 提升面板攻击力的加成（+X%攻击力，含鼓舞、精力充沛） |
| 增益类型 | `攻击力(倍率)` | "攻击力提升至X%"型，仅作用于本次伤害的攻击力乘区、不加算面板（如摆渡人） |
| 增益类型 | `攻击速度` | 直接提升攻击速度（含攻速+N） |
| 增益类型 | `易伤(脆弱)` | 使敌方受到的伤害提升：脆弱/物理脆弱/法术脆弱/元素脆弱，以及"受到的X伤害提升/提高/+X%""受到的X伤害提高N点"等同义写法 |
| 增益类型 | `伤害提升(友方)` | 提升**友方造成的伤害**的加成——既非加算面板攻击力、也非敌方受伤提升；含「造成的X伤害提升」与按目标状态（停顿、恐惧等）增伤等写法 |
| 增益类型 | `附加伤害(友方)` | 为友方的攻击**附带**一段由本干员结算的额外伤害（伤害类型不限：凋亡/灼燃/侵蚀等元素损伤、法术伤害、真实伤害），友方自身造成的伤害不变 |

**生效方式**（增益落到目标身上的时点，可多值并存）

| 组 | 子 TAG | 含义 |
|---|---|---|
| 生效方式 | `在场` | 需该干员在场上才能拿到（常驻光环、攻击/受击触发、需自身阻挡等均记此值） |
| 生效方式 | `编入` | 编入队伍即可，无需在场上 |
| 生效方式 | `携带` | 携带即可，无需在场上 |
| 生效方式 | `部署时` | 部署时/部署后一次性触发（含部署后的限时窗口） |
| 生效方式 | `技能开启时` | 开启技能时触发 |
| 生效方式 | `技能期间` | 技能持续期间生效 |
| 生效方式 | `触发时` | 由特定行为/事件触发，须并记 detail：`造成治疗时`（治疗命中时）、`击倒敌人时`（击倒敌人时）、`装置升级时`（装置技力满升级时）、`吟唱后`（吟唱/演奏完成后结算） |

# 阵容组合

> 依据：`docs/player-tags-specify.md`「阵容组合：这个TAG比较特殊，因为它不是单个干员就可以发挥全部实力的，而是需要阵容内的多个干员配合使用才能发挥最大效果……例如，深海猎人（多名深海猎人的模组加成增幅可叠加）、黍2天赋（天有四时）、怒潮凛冬2天赋&早露2天赋（乌萨斯学生自治团）等」。
> 证据：`material_datas/PRTS/`（431 干员）。行号均为相对 `material_datas/PRTS/` 的真实行号。

## 评定标准

- **记录单元**＝阵营/小队组合；主表**只收「提供者」**（自身文本能为组合内其他干员提供加成/联动条件），纯受益者与计数成员不纳入。
- **纳入**：存在游戏内真实的编队/阵营/小队联动文本——「编入队伍时」「编队中有 N 名【X】干员」「场上每有一名【X】干员」「所有【X】干员获得加成」「【X】干员获得加成效果翻倍」等；天赋、模组、技能、召唤物文本均可，召唤物效果计入持有干员。判据是「该干员**对组合有帮助**」——效果在**计算式中无用**（如默认木桩下无增量的「无视防御与法抗」）**不代表对组合没有帮助**，不得以「算不出增量」为由排除（见 `docs/rulings.md`「阵容组合：『无用』不等于『无助』」）。
- **排除**：仅势力相同但天赋/模组/技能无联动文本的干员；「自身获得」而不是「为组合提供」的文本（如 浊心斯卡蒂的捕食习性仅增强自身，见边界记录）；**非阵营型编队联动不属本 TAG**——职业/类型/条件型编队联动（风笛/黑/年/苏苏洛/凛冬/德克萨斯/银灰/贾维等）统一列在「交叉引用（不属本 TAG）」并指明应归 TAG。
- **与其它 TAG 的关系**：同一干员可出现在多个组合，也可同时出现在其他玩家 TAG（允许重复，见「多 TAG 检查」）。
- **约定**：条件写硬性达成（精英化、模组名与等级、编队/上场要求、编队人数（岁=4、莱欧斯小队=4）、模式限定（ISW-α/RA-α 等））；备注写该干员自己提供的那部分加成（数值取 PRTS 原文，标注潜能5/Rank Ⅲ 数值）及组合整体关键机制。**每个组合的表前以固定三条 bullet 记录组合级信息**——`- **触发条件**：`、`- **组合整体机制**：`、`- **可用受益干员**：名1、名2、…（可带尾注）`；生成结果 JSON 时依次对应组合条目的 `condition` / `remark` / `beneficiaries`。**取档**：模组按对本 TAG 有帮助的最高档取用（按绝对贡献判、不得因更高档拉低比值而改取低档）；持特限证章者：通用线与特限线**分别计算**、UI 分别展示且**特限线优先展示**（细则见 `docs/ui-render-rules.md`）；无特限证章者默认各模组增伤条件均满足并取更高者，所选档写进条件；**只作用于持有者自身的模组线不予纳入**。

- 成员表只含**提供者**；受益者写入 `beneficiaries`（枚举型名单，仅作展示，不参与干员维度筛选；不可枚举的全阵营组合可省略、范围写进备注）。阵营归属按 `## 属性` 的「所属势力」与「隐藏势力」两行并集判定（含隐藏势力成员）。
- 组合排序按「首个成员实装时间」倒序即可；成队人数提示（如「还差几人成队」）当前未入结果 JSON，待前端确定字段后再补规范。
- 同一干员可同时在多个组合、多个 TAG（评定标准：允许重复）；根因在干员维度可拥有多个 TAG 条目，无需去重。

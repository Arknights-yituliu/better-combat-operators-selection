# 充电

## 评定标准

- **纳入**：**本干员机制**（本体 + 技能 + 天赋 + 模组 + 召唤物/装置）能够为**其他干员**回复技力、或加快其技力回复速度的干员（规格原文：「有条件或无条件能够为其他干员加快技力回复速度」）；**只要能为他人回复技力即收，含触发式、击杀式与概率式**。硬性条件写入「条件」（目标职业/技能类型限制、需在场上、精英化、模组等级、模式限定、触发方式），数值与同类取最高规则写入「备注」。
- **排除**：只对**自身**生效的（自身技力自然回复速度+X、攻击/受击/击杀回自身、X 模组「命中精英+1」、自身初始技力等）；只对**召唤物/装置**生效的；非技力资源（魔力等）且不能转化为他人技力的。
- **与其它 TAG 的关系**：多 TAG 允许重复归属，不因「已归拐杖/初动/阵容组合等」排除（黍同属充电/拐杖/阵容组合；嵯峨/矩/罗小黑同属充电/初动；遥同属两表）；仅提供**初始技力 / 部署时技力**类能力者（风笛、凛御银灰、荒芜拉普兰德、炎狱炎熔、新约能天使3、缪尔赛思Y3）归「初动」（互链 `06-初动.md`）。——已在初动中纠正。
- **约定**：数值取 PRTS 原文关键档位（7 级/Rank Ⅲ），技力光环类「同类效果取最高」须写明、避免与其它光环叠加误判；召唤物/装置效果计入持有干员（白铁 S2 装置、娜斯提 S2「监工专员」、掠风「可靠电池」）；触发方式分四类（写入备注）：①持续光环型（铃兰/莫斯提马/白面鸮/黍/归溟幽灵鲨/海蒂）；②装置型（白铁/娜斯提/掠风）；③受击·攻击·治疗·击杀触发型（雷蛇/陈/瑕光/吽/华法琳/塞雷娅/夏栎/森西/嵯峨/矩/罗小黑）；④部署·击杀·其他（推进之王/异客/遥）；模式限定模组（ISW-α/RA-α 等）计入——因此获得充电能力的写入成员表，「条件」写明模式限定、「备注」注明仅该模式可用（异客 RA-α、空弦 ISW-α），任务型限制（海蒂【破碎日冕】）同理。

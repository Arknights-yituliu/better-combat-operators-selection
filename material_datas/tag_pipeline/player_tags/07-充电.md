# 充电

## 评定标准

- **纳入**：**本干员机制**（本体 + 技能 + 天赋 + 模组 + 召唤物/装置）能够为**其他干员**回复技力、加快其技力回复速度、或**补充其弹药类技能的弹药（补弹，见「子 TAG：补弹」）**的干员（规格原文：「有条件或无条件能够为其他干员加快技力回复速度」）；**只要能为他人回复技力或补弹即收，含触发式、击杀式与概率式**。硬性条件写入「条件」（目标职业/技能类型限制、需在场上、精英化、模组等级、模式限定、触发方式），数值与同类取最高规则写入「备注」。
- **排除**：只对**自身**生效的（自身技力自然回复速度+X、攻击/受击/击杀回自身、X 模组「命中精英+1」、自身初始技力等）；只对**召唤物/装置**生效的；非技力资源（魔力等）且不能转化为他人技力的；只为自己补充弹药或使他人的弹药不被消耗的（见「子 TAG：补弹」）。
- **与其它 TAG 的关系**：多 TAG 允许重复归属，不因「已归拐杖/阵容组合等」排除（黍同属充电/拐杖/阵容组合）；击杀触发、概率触发等触发式回复（嵯峨/矩/罗小黑/遥）只属本 TAG，不属 `06-初动增加.md`；仅提供**初始技力 / 部署时技力**类能力者（风笛、凛御银灰、荒芜拉普兰德、炎狱炎熔、新约能天使3、缪尔赛思Y3）归「初动增加」（互链 `06-初动增加.md`）。

**子 TAG：补弹**（为其他干员补充其弹药类技能的弹药；官方机制术语「补弹」）

- **纳入**：技能或天赋可为**其他干员**的**弹药类技能**补充弹药的干员（成员表内标「子 TAG：补弹」者）。
- **排除**：只为自己补充弹药者（圣约送葬人技能闪避后补充自身弹药、烛煌技能自我补充弹药）；使他人的弹药**概率不消耗**者（假日威龙陈「节约风气」，不是补弹）；为其他干员**提高弹药上限**者（上限仅在弹药类技能开始时结算，不向已开启的技能补充弹药；隐现、蕾缪安）；向其他干员提供弹药以外资源者按主 TAG 与其它 TAG 判定。
- **与其它 TAG 的关系**：补弹不回技力，与 `06-初动增加.md` 无交叉；补弹之外另给攻击力/攻速增益的部分按 `08-拐杖.md` 等 TAG 判定。
- **约定**：补弹只对**持有弹药类技能**的干员有实际收益（1技能原文要求目标「开启弹药类技能」）；数值取 PRTS 原文关键档位（7 级/Rank Ⅲ）；补弹于攻击结算时或技能开启时给予，属一次性给予，不构成持续回复；范围与目标选择限制（周围 8 格、优先最后部署者等）写入「条件」「备注」。

- **约定**：数值取 PRTS 原文关键档位（7 级/Rank Ⅲ），技力光环类「同类效果取最高」须写明、避免与其它光环叠加误判；召唤物/装置效果计入持有干员（白铁 S2 装置、娜斯提 S2「监工专员」、掠风「可靠电池」）；触发方式分五类（写入备注）：①持续光环型（铃兰/莫斯提马/白面鸮/黍/归溟幽灵鲨/海蒂/陈）；②装置型（白铁/娜斯提/掠风）；③受击·攻击·治疗·击杀触发型（雷蛇/瑕光/吽/华法琳/塞雷娅/夏栎/森西/嵯峨/矩/罗小黑/推进之王）；④周期·概率触发型（异客/遥）；⑤补弹型（信仰搅拌机，见「子 TAG：补弹」）。模式限定模组（ISW-α/RA-α 等）计入——因此获得充电能力的写入成员表，「条件」写明模式限定、「备注」注明仅该模式可用（异客 RA-α、空弦 ISW-α），任务型限制（海蒂【破碎日冕】）同理。**取档**：模组按对本 TAG 有帮助的最高档取用（按绝对贡献判、不得因更高档拉低比值而改取低档）；有特限证章者优先按其数值、该证章对本 TAG 无贡献时取其它线并写明理由；无特限证章者默认各模组增伤条件均满足并取更高者，所选档写进条件。

# 吃拐一轮秒

> 依据：`docs/player-tags-specify.md`「吃拐一轮秒」段。本 TAG 由两个子 TAG「**聚爆**」「**连射**」构成：满足任一子 TAG 即纳入（可同时归属两个子 TAG，子 TAG 列写「聚爆、连射」），与其他 TAG 多对多并存（**与「决战歼灭」不互斥**）。

## 评定标准

**纳入**：一轮技能内的伤害满足「聚爆」「连射」任一子 TAG 即纳入；两个子 TAG 可同时归属（子 TAG 列写「聚爆、连射」）。
**排除**：不产生对敌伤害的技能（治疗、护盾、屏障、增益、控制、纯损伤铺设）不收；元素损伤／灼燃损伤／凋亡损伤／神经损伤／侵蚀损伤的**损伤值本身**不计（其在爆发期间附带的元素／法术伤害按技能原文计入）；固定数值伤害（「每秒 X 点法术伤害」等）无法折算倍率，不计。
**与其它 TAG 的关系**：与「决战歼灭」**不互斥**——同一干员的不同技能可分别满足两 TAG，同一技能亦可同时满足；与「次数对策」的分工：次数对策看「段数／跳数够不够密」，本 TAG 看「单轮爆发够不够快、够不够大」，交叉成员同属两 TAG。
**约定**：召唤物／装置／棋子造成的伤害与触发计入持有者；模式限定模组（ISW-α／RA-α／SO-α／SO-β 等）与模式限定天赋同等计入，条件写明模式；必生效的天赋／特性／模组乘算计入；数值取 Rank Ⅲ（专精3）；面板攻击力＝满信赖 ＋ 最高精英化阶段满级 ＋ 有效潜能最高档 ＋ 条件点名模组档位的固定属性（攻击+N），**并入后倍率数值不变**（仅面板数字与绝对伤害随之更新）；**模组按对本 TAG 有帮助的最高档取用**——更高档若在倍率、段数或伤害窗口等本 TAG 判据上无新增帮助则不取，所选档写入条件（同一条件并列多个模组档时，取对**本 TAG 所需方向**加成最高的那一档，不得两档叠乘）；**潜能**的加成按对本 TAG 是否有帮助取舍，有帮助的潜能档计入并在条件写明「潜能N」，多档均有帮助时取最高（同一干员的不同 TAG 各行可依据不同潜能档）；潜能的面板攻击加成并入面板基准（面板＝满信赖＋最高精英满级＋有效潜能最高档）；**双情形呈现**：可通过溢出机制把超额资源转化为输出者，按「完全溢出」（超额资源一瞬间全部结算、不计窗口时间）与「完全不溢出」两种成绩分别计算；本体达标而召唤物／装置／特勤等附加因素可提成绩者，列「仅本体」与「全因素计入」两种成绩；多情形成绩列在备注开头（例：望、机械师）；成绩项与推算值写法见 `docs/concept.md`。

**子 TAG：聚爆**（伤害窗口 ≤10 秒 且 对同一目标总倍率 ≥2000%）

- **纳入**：一轮技能内、**伤害集中在 ≤10 秒的窗口内打完**（瞬爆型：瞬发／连斩／单轮多段／弹药倾泻；持续型长轴输出不收），且对**同一目标**可累计的总倍率 **≥2000%**。
- **伤害窗口**：瞬发＝0 秒；连斩／多段＝`段数 × 段间隔`；周期性结算＝`跳数 × 跳间隔`；弹药制＝`弹药数 ÷ 每次消耗 × 实际攻击间隔`；**弹药倾泻**＝实际倾泻耗时；多阶段技能按最后一段结算完毕计；连斩型技能原文未给每击间隔者，按每击 ≤0.4 秒计。
- **总倍率**：`总倍率＝Σ（每段倍率 × 段数 × 命中同一目标的次数）`；可叠加在同一目标上的多枚弹体／多次结算按**叠加**计（如梅尔多只机械水獭同时引爆压在同一目标）；「对最多 N 名敌人各造成 X%」这类**不叠加**的对多目标计法只计单体 X%；**必定生效**的天赋／特性／模组乘算须计入（例：锏 S3 使天赋发动率提升至 100% → 每段 235%×160%≈376%）。
- **排除**：窗口 >10 秒的持续型长轴输出；单体累计 <2000%；关闭技能只能直接停止、剩余弹药作废（原文无[弹药倾泻]）的弹药制技能不按倾泻计时。
- **约定**：弹药倾泻仅限技能原文写明「主动关闭时发射剩余全部弹药／发动一轮[弹药倾泻]」者；倾泻速率原文写明者从原文，未写明（「每隔？」）者按每 2 帧发射 1 枚（2 帧＝0.067 秒），原文明说「一次性发动／发射全部」者按一瞬间结算（窗口≈0）。

**子 TAG：连射**（满足以下任一即纳入）

1. **间隔档**：造成的为**物理伤害**，且技能期间单次攻击之间的攻击间隔 **≤0.2 秒**（只看技能文本的间隔改写值，不并入攻速；不含强力击类技能）。
2. **段数档**：造成的为**物理伤害**，且一轮技能打完对**单个敌人**造成的伤害段数 **≥80**。`段数＝Σ（每次攻击段数 × 攻击次数）`；**群攻 × 目标数仅在「多个目标的伤害可叠加于同一目标」时乘算，否则按 1 计**；弹药制按 `弹药数 ÷ 每次消耗` 折算；附加伤害实例计段，概率触发按**期望触发次数**计（写明触发率与算式）。
3. **次数档**：一轮技能攻击 **≥25 次**（含召唤物／棋子的攻击与触发），且平均每次攻击的总倍率 **≥250%**（必定生效的天赋**和模组**加成计入），且**技能期间单次攻击之间的攻击间隔 ≤1.5 秒**。
- **计数方式**：条件②③的攻击次数按**实际攻速**计（`实际间隔＝基础或技能改写间隔 × 100/(100+攻速)`，攻速含技能／天赋／模组原文写明的必生效值；`攻击次数＝持续 ÷ 实际间隔`，四舍五入、含首击）；条件①只看技能文本的间隔改写值。**次数档的达标计数只取间隔 ≤1.5 秒 的攻击来源**（同一技能内间隔越线的来源不计入达标次数）。
- **排除**：法术／真实伤害技能不收条件①②（其达线者走条件③）；对多目标分摊、不能叠加于同一目标的段数不算单目标段数；无「一轮」边界（持续时间无限且无弹药／段数上限）的技能不收；强力击型（「下次攻击造成 X%」）段数远低于线，不收。
- **约定**：技能带「过载」状态者按 `docs/glossary.md` 的过载定义计——额外效果只覆盖技能后半程，前半程按常态数值；**分段各半**（时间型按技能持续时间对半、弹药型按弹药总数对半，即自弹药剩余量降至一半起）。

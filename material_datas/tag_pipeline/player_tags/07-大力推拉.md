# 大力推拉

## 判定口径

- 纳入：干员**可达成「大力」及以上失衡力度**的推/拉/拖拽/击退/弹开类位移（本体技能、天赋、模组、召唤物/装置均计入，召唤物技能归其持有者）。力度以 PRTS 技能原文为准，档位为 小力 < 中等力度 < 较大力 < 大力（原文未出现"巨力"技能描述，仅山的天赋名"巨力重拳"含此二字，非力度档）。
- **+1 级效果计入**：原文"力度提升一个等级""推力增加一级"类效果按提升后的档位判定，但必须把触发条件写入「条件」（如 温蒂 Y 模组的"阻挡≥2名敌人时"+1、雪雉天赋的"仅【感染生物】"+1、歌蕾蒂娅 Y 模组的"目标距离>2.5格"+1）。
- **模式限定模组（ISW-α / RA-α 等）计入**（开发者最新口径）：因此达成大力的写入成员表，条件注明"仅集成战略/生息演算"，备注注明模式限定。
- 边界处理：只达**较大力 / 中等力度**的进「边界与排除记录」单列，供开发者确认是否放宽门槛；只达小力及以下的、以及传送/诱导/缚地/失重/浮空等非失衡位移机制，明确排除。
- 条件写硬性前提（精英化、技能、专精档位、模组及等级、目标限制）；备注写力度档位、方向（推开/拉向/双向/径向）、可否对空、距离/半径、伤害与附加效果（晕眩/停顿/真实伤害/移动创伤等）、特殊用法（如温蒂3双大力推叠加）。

- **缚地 / 浮空**：予愿安洁莉娜（缚地入坑）、雪绒（浮空）等。
- **失重**：霍尔海雅、安洁莉娜、予愿安洁莉娜——失重为减重效果、本身不产生位移，但可放大推拉/入坑杀效果（组合向，不进本表）。

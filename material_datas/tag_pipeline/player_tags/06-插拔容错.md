# 插拔容错

## 评定标准

- **specify 原文**：「插拔容错：类似缄默德克萨斯、麒麟R夜刀、耀骑士临光2等。如果某个干员的救急能力有硬性条件，则写在条件里，例如耀骑士临光需要精英化1。对于救急的类型，写在备注里，例如耀骑士临光为单切，缄默德克萨斯3为群控等。」
- **纳入（三条路径，满足其一即可）**：
  - ① **低再部署循环**：基础再部署 ≤25s（处决者 18s / 弑君者 22s / 行商 25s），或自带天赋/模组使再部署大幅缩短并达到可循环水平（伊内丝 AGE-Y「首次撤退再部署-35%」≈23s、麒麟R夜刀 Y模「首次撤退再部署为 0」、艾丽妮 ISW-α「-60%」≈28s、佩佩 RA-α「-90%」≈7s）。
  - ② **部署即生效/不占部署位/撤退收益**：耀骑士临光 S2（部署不消耗部署位、技能结束自动撤退）、**陷阱师（附加标准：陷阱的触发范围与作用范围扩大或可直接部署在地面敌人所在格，且部署后立即可触发）**、召唤物承载型（凯尔希 Mon3tr 25s 短再部署）。
  - ③ **初动为满的落地点火技能**（示例 陈2）：技能**初始技力 ≥ 消耗**（含 0 技力的「部署后」被动技能），部署后即可立即开启并承担救急职能（群控/群伤/单切/治疗/减伤/回费）。
- **条件**：技能开放所需的精英化与专精、达成再部署或效果所需的模组等级；模式限定模组（ISW-α / RA-α）必须写入条件，备注注明仅该模式可用（依据 `_brief.md` §2.3）。
- **评定标准落实（`docs/judge-for-player-tags-members-1.md` / `-2.md`「插拔容错」）**：
  - **陷阱师**：望（3技能「触发与伤害范围扩大」，范围内可直接将陷阱部署在地面敌人所在格）、艾拉（地雷触发半径1.35、效果影响半径1.7）满足路径②附加标准；多萝西、霜华、罗宾、钼铅不满足，见「已定评定标准」与「纳入存疑」。
  - 12 名「不占用部署位」支援机械**移出主表**（产生的效果太低，耀骑士临光除外）→ 见边界。
  - 召唤物承载型**凯尔希纳入**（Mon3tr 短再部署）。
  - 「初动满落地点火」标准已全库扫描，原边界中的黑键/玛露西尔/蕾缪安/赤刃明霄陈/斩业星熊均不满足，保留边界。
  - 情报官 35s **一般不纳入**，仅伊内丝因落地控制保留；弑君者 22s 保留。
- **排除**：仅自身增益/形态切换、需长技力暖机、无落地即生效手段者；无救急职能的部署时类效果；陷阱师中不满足上述附加标准者（多萝西/霜华/罗宾/钼铅，见「纳入存疑」）。

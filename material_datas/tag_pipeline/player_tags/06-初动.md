# 初动

## 评定标准

- **纳入**：**本干员机制**（本体 + 天赋 + 技能 + 模组 + 召唤物/装置）能够为**其他干员**在**开局/部署时点一次性增加技力（含原文「初始技力」）**、或**通过触发方式为其他干员增加技力**的干员（规格原文：「类似风笛、凛御银灰等一众可使干员初始技力增加的干员」）。**触发式纳入**：击杀触发（嵯峨/矩/罗小黑：击杀者技力+1/+2）与概率触发（遥 Y 模组：浮泡破碎 10%/20% 概率+1）同样计入。——击杀触发和概率触发属于充电，而非初动。除此之外，将初动重命名为“初动增加”。初动增加是只能够让干员初始技力增加的干员。
- **排除**：仅自身的初始/部署时技力；费用类；再部署时间类；只对召唤物/装置生效的；非技力资源与特殊技力机制（琳琅诗怀雅「金币」、玛露西尔「魔力」属特殊机制，不计入）。
- **与「充电」的关系**：充电＝持续回复速度／回复量及触发式回复（`07-充电.md`）；初动＝开局/部署时点的一次性给予，以及触发式为他人增加技力（嵯峨/矩/罗小黑/遥 同时在两表）。
- **约定**：数值取 PRTS 原文关键档位（专三/7级/模组等级/精英阶段），潜能为数值档位写入备注（如「潜能5后+N」）；硬性条件（精英化、模组及等级、职业/阵营/位置限制、是否需在场、是否编入队伍即生效、触发方式）写入「条件」，给予方式（编入队伍/部署时/其他触发）与具体数值写入「备注」；模式限定模组（ISW-α/RA-α/SO-α 等）若提供为他人初始技力的能力则计入并写明模式限定——本 TAG 无此类成员（模式限定模组中的技力效果均为自身，见排除记录）。

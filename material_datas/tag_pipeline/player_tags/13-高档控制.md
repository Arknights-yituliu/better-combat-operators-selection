# 高档控制

> 依据：`docs/player-tags-specify.md`。本 TAG 由三个子 TAG「**大力推拉**」「**阻挡数5**」「**长效控制**」构成——满足任一子 TAG 即纳入；成员表按子 TAG 分表，同一干员可属多个子 TAG。

## 评定标准

**纳入**：干员的能力满足「大力推拉」「阻挡数5」「长效控制」任一子 TAG 的判据即纳入；一个干员可同时归属多个子 TAG（成员表按子 TAG 分表）。
**排除**：对敌人**不产生位移、阻挡或控制**的能力不收；三个子 TAG 各自的排除条见下。
**与其它 TAG 的关系**：与「拐杖」（增益向）、「保人」（防护向）、「次数对策」（段数向）等互不排斥——同一技能可分别满足不同 TAG 的判据（如 珊比 3技能 同时满足「阻挡数5」与「长效控制」）。「大力推拉」对应官方设定 TAG 的「推拉位移（失衡位移）」；**传送、诱导、浮空、失重**等官方单列的机制归「长效控制」子 TAG 判。
**约定**：控制类效果一律按**木桩敌人**口径折算（攻击间隔 2.5 秒、可被阻挡、**不计其无冷却的首击**）；模式限定模组（集成战略／生息演算／岁的界园志异 特限）计入，条件写明模式；模组写法为「中文线名（代号）」（如 `Y模组3级（PUS-Y）`、`集成战略特限模组3级（ISW-α）`）；成绩块单情形一律裸 `成绩`；条件写硬性前提，备注写数值、隐藏机制与特殊用法。

**子 TAG：大力推拉**（门槛＝「大力」及以上失衡力度）
- **纳入**：干员**可达成「大力」及以上失衡力度**的推/拉/拖拽/击退/弹开类位移（本体技能、天赋、模组、召唤物/装置均计入，召唤物技能归其持有者）。力度以 PRTS 技能原文为准，档位为 小力 < 中等力度 < 较大力 < 大力（原文未出现"巨力"技能描述，仅山的天赋名"巨力重拳"含此二字，非力度档）。达到「大力」需附带触发条件的（如"阻挡2个及以上敌人时""仅【感染生物】""目标距离>2.5格"），把触发条件写入「条件」。
- **排除**：最高力度只达**小力及以下 / 中等力度 / 较大力**的位移不收（门槛为「大力」）；传送、诱导、缚地、失重、浮空等不产生失衡力度位移的机制不收（这些机制如有长效控制价值，归本 TAG 的「长效控制」子 TAG 判）。各档位被排除的干员逐条见「边界与排除记录」。
- **约定**：+1 级效果计入，力度记作「大力+N」：原文"力度提升一个等级""推力增加一级"类效果按提升后的档位判定，超过原文"大力"档的记作「大力+1 / 大力+2」（**档位名 PRTS 未给出**）；模式限定模组（ISW-α/RA-α 等）计入，达成大力的写入成员表，「条件」注明模式限定（仅集成战略/生息演算）、「备注」注明仅该模式可用；条件写硬性前提（精英化、技能、专精档位、模组及等级、目标限制），备注写力度档位、方向（推开/拉向/双向/径向）、可否对空、距离/半径、伤害与附加效果、特殊用法（如温蒂 3 技能本体与蓄水炮的双大力推叠加）。

**子 TAG：阻挡数5**（门槛＝**有效阻挡数 ≥5**，不是 =5）
- **纳入**：**本干员自身机制**（本体 + 技能 + 天赋 + 模组 + 召唤物/装置）能够使**某一个实体独立**达到有效阻挡数 ≥5 的干员。有效阻挡数 = 本体阻挡（含"已计入基础数值"的模组加成）+ 技能/天赋/模组加成；召唤物按其自身有效阻挡数判定，本体与召唤物分属不同地块的阻挡数**不相加**。
- **排除**：只提高**友方**阻挡的（年 3 技能、海蒂、可露希尔 2 技能的"援军"、帕拉斯、娜斯提、风絮、执旗手系模组等）；自身加成后仍 <5 的；把多个独立实体的阻挡数相加凑到 5 的；复制型召唤物（缪尔赛思"流形"）：复制的干员不能开启其本身技能，除非某干员在**待部署位时就显示**阻挡数 ≥5。
- **约定**：按「最大可达阻挡数」判定，写清每个加成来源（精英化、技能、模组及等级），阻挡数不在专精档位变化的不写专精要求；迷狂牢笼只计**可阻挡**的敌人（持有【不可阻挡】的单位不计入，见 `docs/official-tags-members.md` §8.1）；模式限定模组（ISW-α/RA-α 等）计入，使阻挡数达 ≥5 的写入成员表并在「条件」中写明模式限定；备注只写数值/隐藏机制/特殊用法，不写「不占部署位」类玩家直觉。
**子 TAG：长效控制**（门槛＝**等效剥夺时长 ≥15 秒**）
- **纳入**：干员能以自身机制（本体／技能／天赋／模组／召唤物／装置）**持续剥夺敌人的行动能力**、且**等效剥夺时长 ≥15 秒**者。**等效剥夺时长**＝控制效果真正阻止敌人行动的时间：有明文时长者按明文；需折算者按木桩敌人的行动设定（**攻击间隔 2.5 秒、可被阻挡、不计其无冷却的首击**）折成「被剥夺的攻击节拍数 × 2.5 秒」。
- **排除**：等效剥夺时长不足 15 秒的控制不收；单纯减速、单纯失重（不剥夺行动）不收。
- **约定**：按单一木桩敌人计；同时控制多名敌人不折算时长；控制被其它效果延长的，按该控制效果自身可剥夺的节拍计。

### 非失衡位移机制的归属
传送、诱导、缚地、浮空、失重等不按失衡力度档计的机制不属「大力推拉」（其门槛为失衡力度档），它们是否有控制价值由「长效控制」按等效剥夺时长判：达到 ≥15 秒者列入成员表，不足者仍列排除并写明时长。

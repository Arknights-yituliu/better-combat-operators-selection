# 远程消耗

## 判定口径

- 依据 `docs/player-tags-specify.md`：「远程消耗：类似荒芜拉普兰德3、澄闪3、安比尔2等。如果某个干员的远程能力有硬性条件，则写在条件里……对于打数和特殊效果，写在备注里」。
- **纳入标准（三类）**：
  - **A 打击范围越界**：技能/天赋/模组使自身攻击（含浮游单元、光束、锁定弹道）可打到自身**常规攻击范围之外**的区域——原文出现「整个战场」「全场」「无限长的直线」「可以攻击到范围外被阻挡的敌方单位」等表述，**以及经机制"扩展出的"超远距离攻击**（如谬因的射程无限延伸+中继器转向）；要求为**持续/永续/可反复**的消耗手段。
  - **B 远程部署型召唤物与装置**（开发者裁决纳入）：召唤师召唤物、陷阱师陷阱、鸿雪「打字机」等可部署于自身射程之外的区域并持续/反复造成伤害的单位；**召唤物/装置效果计入持有干员**（含集成战略限定模组）。
  - **C 全场触发式/周期式伤害**（开发者裁决纳入）：天赋/技能对**全场**敌人结算伤害，但为**触发式或周期式、非持续消耗**——照收，备注必须写明"触发式、非持续消耗"或"周期式（每X秒）"（如异客 RA-α 雷击）。
- **排除标准**：① 射程只比常规略远（攻击范围+1~2格、攻击距离+1、改为前方固定格数）或仅"攻击范围扩大"而无越界/扩展文本；② 一次性爆发且无全场/越界性质；③ 纯控制、纯减益（脆弱/攻速-）、纯增益、纯治疗；④ 自身增益（全场有敌人XX时自身攻击力+）。
- **模式限定模组（ISW-α / RA-α 等）计入**（开发者最新口径）：因此获得的能力写入成员表，条件注明模式限定，备注注明仅该模式可用。
- **全场光环类移出本表**：塑心 Y 模组、安洁莉娜 ISW-α 等"全场持续伤害光环"已按开发者裁决归入**官方设定 TAG「全场光环」（docs/tags.md 类别 I）**（含莫斯提马2天赋等；区分增伤光环/伤害光环/削弱光环子 TAG）——本表不重复收录，见「边界与排除记录」互链。
- **召唤物部署范围的口径 [待考]**：仓库 PRTS 未收录攻击范围网格，召唤物数据中「部署位置」仅区分近战位/远程位/全部位，未记载与持有者射程挂钩的约束；以凯尔希天赋原文"Mon3tr不在凯尔希攻击范围内时防御力降至0"（凯尔希/凯尔希.md:54-56）可佐证召唤物**可**部署于持有者射程之外（代价另计）。若后续补抓范围网格需同步复核本表。
- 条件写硬性前提（精英化、技能、专精档位、模组及等级、召唤物/陷阱类型、目标限制）；备注写射程表述、召唤物射程与部署位置、持续/再部署、打数、每秒伤害/倍率、附带效果、占用（部署数/人口）与限制。

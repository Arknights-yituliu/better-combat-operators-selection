| 分支信息 | |
| * <替身>是此分支干员拥有的“二阶段”能力。 * 初始处于<本体>形态，此形态下受到足以致命的伤害且未持有[不死](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")的情况下，干员会在一段切换动画后，切换为<替身>形态战斗，持续20秒（期间持有[阻回](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")）。部分机制也可以直接让干员切换为<替身>形态，或是拥有多种机制不同的<替身>形态。 * <替身>形态持续时间结束时干员会在一段切换动画后，切换回<本体>形态。 * 切换动画期间会清除自身一切Buff；切换途中重设自身生命至最大值，随后再次清除自身一切Buff（存疑）。 * 切换动画期间干员持有以下效果：[不死](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[无敌](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[阻回](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[禁疗](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[孤立](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[强制缴械](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[晕眩免疫](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[冻结免疫](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[沉睡免疫](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")。 * <本体>形态下，干员可以且优先攻击自身阻挡的单位（即使目标处于攻击范围外或为飞行单位）；<替身>形态下阻挡数最终×0（通常从切换至<替身>开始时持续至切换回非<替身>开始）。 | |

**PUM-Y**

**彼此的声音**

**基础信息**  全文阅读

一个下午，太阳炽热地挂在天上，吉阿达指了指面前的仓库，裘里奥和结城理一起使劲拉起了卷帘门。  
仓库里倒是阴凉，吉阿达走到某排储物架前，说：“这些是她的。”吉阿达让裘里奥把东西在旁边的桌子上都检视一遍，理站在裘里奥身旁，帮他把确认留下的物品放进纸箱。  
“这是……”裘里奥打开一个储物盒，感叹道，“好老的歌啊。”  
他问吉阿达：“这些都是姨妈收藏的磁带吗，你研究遗物的时候是不是听过？”吉阿达摇摇头：“没有听完全部……也不全都是收藏。”  
吉阿达拣出几盘样子朴素的，说：“这些应该是她自己录的。我和结城提过，在遗物里听到了一首歌，就是在这里。”理有点疑惑，裘里奥则好奇地问：“哪一盘？我也想听。”  
吉阿达犹豫了一下，拿出一盘磁带放进旁边的收音机，插上电，按下了播放键。  
家庭录制的磁带响着沙沙声，没有伴奏，略微沙哑的女声唱着柔情又依恋的歌，裘里奥却渐渐想要落泪。下午的阳光照进了仓库里，耀眼的白光落在地上像水波。  
“……糖与铳与信心，我将拉特兰一饮而尽。”他低声跟着唱完了最后几句。  
音乐结束了，最先说话的竟然是理：“我想起来了，吉阿达小姐当时说的话……所以，你对葬礼的坚持，其实是与这首歌有关吗？”  
吉阿达说：“……嗯。这盘磁带，应该就是不久前录的……不过，只是听到一首歌的心情，我把它当成逝者的意愿，还是太自以为是了。”  
理摇了摇头：“音乐确实能告诉我们很多事。”  
“……这样说来，理似乎经常在听音乐呢。”裘里奥低头抹了一下眼睛，又恢复了平时的笑容。  
“还好……”话题突然转移到自己身上，理猝不及防，吉阿达却悄悄松了一口气。裘里奥又问：“理平时都听什么歌呢？”  
“……这些，也可以给大家听。”理启动随身携带的播放器，给两人看了看。  
“其实，听同一首歌是不是就有点像共感？”裘里奥摸摸自己的下巴，突然说。  
“除了你这里谁也不知道共感是什么感觉吧……”吉阿达忍不住说。  
“……我好像能明白。”理却认真地回答了。  
吉阿达突然想起了一件事。在那一天，那一个傍晚，她曾体会过的。在那最后，她确实听到了音乐声，如星光、如晚霞一般的大提琴声。  
“……那也许，我也感受过。”吉阿达说。  
“是吧，音乐也是能听见的心情呢。”裘里奥温柔地笑着。  
“能体会他人心情的办法，一直都是存在的。”理看向裘里奥，认真地说，“有很多东西都可以把我们连系在一起。”  
“那样的时刻只要存在过，就不会消逝了。”他说。

一个下午，太阳炽热地挂在天上，吉阿达指了指面前的仓库，裘里奥和结城理一起使劲拉起了卷帘门。  
仓库里倒是阴凉，吉阿达走到某排储物架前，说：“这些是她的。”吉阿达让裘里奥把东西在旁边的桌子上都检视一遍，理站在裘里奥身旁，帮他把确认留下的物品放进纸箱。  
“这是……”裘里奥打开一个储物盒，感叹道，“好老的歌啊。”  
他问吉阿达：“这些都是姨妈收藏的磁带吗，你研究遗物的时候是不是听过？”吉阿达摇摇头：“没有听完全部……也不全都是收藏。”  
吉阿达拣出几盘样子朴素的，说：“这些应该是她自己录的。我和结城提过，在遗物里听到了一首歌，就是在这里。”理有点疑惑，裘里奥则好奇地问：“哪一盘？我也想听。”  
吉阿达犹豫了一下，拿出一盘磁带放进旁边的收音机，插上电，按下了播放键。  
家庭录制的磁带响着沙沙声，没有伴奏，略微沙哑的女声唱着柔情又依恋的歌，裘里奥却渐渐想要落泪。下午的阳光照进了仓库里，耀眼的白光落在地上像水波。  
“……糖与铳与信心，我将拉特兰一饮而尽。”他低声跟着唱完了最后几句。  
音乐结束了，最先说话的竟然是理：“我想起来了，吉阿达小姐当时说的话……所以，你对葬礼的坚持，其实是与这首歌有关吗？”  
吉阿达说：“……嗯。这盘磁带，应该就是不久前录的……不过，只是听到一首歌的心情，我把它当成逝者的意愿，还是太自以为是了。”  
理摇了摇头：“音乐确实能告诉我们很多事。”  
“……这样说来，理似乎经常在听音乐呢。”裘里奥低头抹了一下眼睛，又恢复了平时的笑容。  
“还好……”话题突然转移到自己身上，理猝不及防，吉阿达却悄悄松了一口气。裘里奥又问：“理平时都听什么歌呢？”  
“……这些，也可以给大家听。”理启动随身携带的播放器，给两人看了看。  
“其实，听同一首歌是不是就有点像共感？”裘里奥摸摸自己的下巴，突然说。  
“除了你这里谁也不知道共感是什么感觉吧……”吉阿达忍不住说。  
“……我好像能明白。”理却认真地回答了。  
吉阿达突然想起了一件事。在那一天，那一个傍晚，她曾体会过的。在那最后，她确实听到了音乐声，如星光、如晚霞一般的大提琴声。  
“……那也许，我也感受过。”吉阿达说。  
“是吧，音乐也是能听见的心情呢。”裘里奥温柔地笑着。  
“能体会他人心情的办法，一直都是存在的。”理看向裘里奥，认真地说，“有很多东西都可以把我们连系在一起。”  
“那样的时刻只要存在过，就不会消逝了。”他说。

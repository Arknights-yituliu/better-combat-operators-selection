| 分支信息 | |
| * <替身>是此分支干员拥有的“二阶段”能力。 * 初始处于<本体>形态，此形态下受到足以致命的伤害且未持有[不死](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")的情况下，干员会在一段切换动画后，切换为<替身>形态战斗，持续20秒（期间持有[阻回](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")）。部分机制也可以直接让干员切换为<替身>形态，或是拥有多种机制不同的<替身>形态。 * <替身>形态持续时间结束时干员会在一段切换动画后，切换回<本体>形态。 * 切换动画期间会清除自身一切Buff；切换途中重设自身生命至最大值，随后再次清除自身一切Buff（存疑）。 * 切换动画期间干员持有以下效果：[不死](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[无敌](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[阻回](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[禁疗](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[孤立](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[强制缴械](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[晕眩免疫](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[冻结免疫](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[沉睡免疫](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")。 * <本体>形态下，干员可以且优先攻击自身阻挡的单位（即使目标处于攻击范围外或为飞行单位）；<替身>形态下阻挡数最终×0（通常从切换至<替身>开始时持续至切换回非<替身>开始）。 | |

## 特性

| 分支 | 描述 |
| --- | --- |
| 回环射手 回环射手 | 持有回旋投射物时才能够攻击（投射物需要时间回收） |
| 分支信息 | |
| * 每次攻击投掷的回旋投掷物具有一定的飞行速度，投掷物会抵达目标的**判定中心**并击中目标，随后在没有**后续运动模式**的情况下，会从目标处回到干员处。 * 必须回收全部回旋投掷物才可以进行攻击。 * 干员属性中的攻击间隔为其最短攻击间隔，实际攻击间隔会受投掷物的实际飞行时间影响产生浮动，可影响的因素包括且不限于：目标与干员的直线距离、投掷物的后续运动模式。 | |
| 备注 | |
| * 投射物飞行速度15，返回时飞行速度3.75 | |

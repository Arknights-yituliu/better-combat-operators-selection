| 备注 | | | | | | | |
| ※当“弦惊”部署时：  1）当自己攻击范围内存在其他基础形态的“弦惊”，将自身作为**素材**，那只其他“弦惊”作为**对象**。撤离作为素材的自己，并将作为对象的“弦惊”升级成高级形态。  2）当自己没有因第一条而撤离的情况下，若自己处于其他一个或数个基础形态的“弦惊”攻击范围内，将那些“弦惊”中最晚部署的那一只作为**素材**，自身作为**对象**。撤离作为素材的那只“弦惊”，并将作为对象的自己升级成高级形态。  ※升级时立刻重设召唤物生命值至最大值，并额外占据一个部署数。  ※高级形态下：生命上限+100%，攻击力+80%，防御力+80%，法术抗性+100%，攻击间隔+0.8s，阻挡数+2。计算方式均为直接加算或直接乘算。  ※在高级形态下，技能开启时，上述加成会瞬间失效再瞬间重新生效，因此会“先判定阻挡数-2解除阻挡，再重新判定阻挡数+2重新去阻挡敌人”。 | | | | | | | |

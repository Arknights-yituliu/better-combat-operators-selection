## 特性

| 分支 | 描述 |
| --- | --- |
| 链愈师 链愈师 | 恢复友方单位生命，且会在3个友方单位间跳跃，每次跳跃治疗量降低25% |
| 分支信息 | |
| * 普通攻击产生治疗，优先治疗生命比例最低的友方单位；进行治疗时，选择目标所在格上的单位作为治疗链的主目标。 * 跳跃范围为，无特殊说明的场合一次治疗链不会对已跳跃过的单位重复跳跃。 * 跳跃时的治疗量衰减为攻击力倍率降低，每次治疗的倍率均为前次倍率的75%（1-25%）。 * 部分干员的治疗跳跃存在“不会衰减的额外跳跃对象”的机制，当治疗跳跃到符合条件的单位时（不论是否成功治疗），本次跳跃治疗目标数+1，且下次治疗的倍率将保持与本次倍率一致。 * 优先跳跃至范围内生命比例最低＞部署时间点最晚的我方单位。可选择满生命我方单位为跳跃目标，但仍受[禁疗](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")制约。 | |

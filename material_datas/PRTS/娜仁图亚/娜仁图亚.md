## 特性

| 分支 | 描述 |
| --- | --- |
| 回环射手 回环射手 | 持有回旋投射物时才能够攻击（投射物需要时间回收） |
| 分支信息 | |
| * 每次攻击投掷的回旋投掷物具有一定的飞行速度，投掷物会抵达目标的**判定中心**并击中目标，随后在没有**后续运动模式**的情况下，会从目标处回到干员处。 * 必须回收全部回旋投掷物才可以进行攻击。 * 干员属性中的攻击间隔为其最短攻击间隔，实际攻击间隔会受投掷物的实际飞行时间影响产生浮动，可影响的因素包括且不限于：目标与干员的直线距离、投掷物的后续运动模式。 | |
| 备注 | |
| * 投射物飞行速度15，返回时飞行速度3.75 | |

### “吹尽狂沙”

![](https://torappu.prts.wiki/assets/uniequip_img/uniequip_002_narant.png)

![](https://torappu.prts.wiki/assets/uniequip_type/lps-x.png)

**LPS-X**

**“吹尽狂沙”**

**基础信息**  全文阅读

娜仁图亚从夜梦中惊醒，喉咙里仿佛含着一块热炭，耳朵里仍是梦中响起的金铁相击之声，令她难以忍受。  
她走出帐篷，荒漠顶上无月，风似远征的骑兵，狂奔向沙漠深处。  
“叮！铛！”那打铁一般的声音愈发响亮。娜仁图亚四处寻找声音的源头，却意外发现自己腰间的黑色弯刀正颤抖不止。  
她握住刀柄，本以为这样便能止住它的躁动，没想到反而令其势更盛，将她震得手臂发麻、头晕目眩。  
“停下！”她怒吼着，将那把刀抓得更紧。  
黑色的弯刀拽着她，使她踉踉跄跄地跑进了夜色里。  
她看到一柄如同山岭的巨锤，重重砸落在火红的铁砧之上，一声声战鼓，一阵阵金铁的嘶鸣，火星飞溅，巨锤不屑于铸造凡铁，它竟然将那坚不可摧的铁砧砸成了一把刀！  
战鼓声越来越清晰，她看到有人接过了那把刀，行走在远征队伍的最前面，用它劈开坚硬的骨头，用它斩落歪斜的旗帜，直到那人死去，刀落进黄沙里。娜仁图亚若有所悟，自己此刻正站在那片黄沙之上！  
“......不，”她说，“那不是我！”  
她不再试图遏止弯刀的躁动，狠狠地扔出弯刀，似乎要用它击碎那片风沙中的幻景。  
“无论你是什么来历，我都不在乎！我有我自己的路，如果你不愿意跟我走，那随便你！”  
娜仁图亚不确定自己有没有喊出这句话，因为下一刻，她狠狠摔进了荒漠里。  
......  
娜仁图亚醒来时，一旁的酒友正关切又畏惧地给她摇着扇子。  
“我喝多了？”  
正在往酒里掺水的摊主赧然一笑。  
“我的刀呢？！”娜仁图亚手往腰间一拍，冷汗立刻冒了出来。  
酒友们将她引到一块巨岩前。  
“娜仁图亚，你究竟是怎么做到的？”  
娜仁图亚揉了揉眼睛，那把深深插进巨岩的黑色弯刀的确是自己的。她试着往外拔，但刀与石头都纹丝未动。  
“昨晚天上打了几个雷，你醉醺醺地从帐篷里出来，对着阴云破口大骂，然后就拔出刀往这大石头上一砸！”一名酒友龇着牙说，“太吓人了，等会儿我就把欠你的酒钱都还你......”  
“的确吓人，我还记得你最后大声喊了一句——”  
“我喊了什么？”娜仁图亚此时已经回忆起了一些片段，她甚至有些佩服自己能想出那样霸气的宣言，她并不介意再听别人讲一遍。  
“你喊的是——‘如果你再不老实，我就把你卖了，换一把纯金的！’”  
“什么？等等，难道不是......”  
“唔，就是这句，我也听到了。的确是娜仁图亚会说的话。”  
“......”

阿雅吉和阿雅妮并非亲姐妹，而是被沙盗从不同地方抓来的奴隶，名字也是自己起的。

裂兽族母陷入沉默。  
“看来你觉得不划算？”娜仁图亚啐了一口，“那就滚！”  
被激怒的裂兽纷纷咆哮，娜仁图亚也扯嗓子仰天怒吼，回敬以自己的态度。

裂兽族母叼起盐包，带着族群退回荒原深处。  
“走吧，回家。”娜仁图亚嗓音发哑，“既然收了你们当手下，以后就得听我的话，不能乱跑了。”  
“你、你什么时候收我们当手下了？而且，你不是说再也不当老大了吗？”  
“没办法，我也不想当老大，但我总不能看着你们去死吧？你们要是不愿意，我可以把裂兽叫回来。”  
阿雅吉闭上了嘴。阿雅妮凑近说：“这个老大能吓走一群裂兽欸，将来肯定有出息。”  
阿雅吉叹了口气：“我们俩现在都欠她一条命，这可该怎么报答呀？总不能给她当一辈子手下吧？”  
“阿雅吉，这已经是她第二次救我们了，一辈子可能都不够的。”  
娜仁图亚头也没回地应道：“我不需要你们报答我，我也没那耐心给别人当一辈子老大！将来哪天咱们散伙，过上安稳日子了，只要你们还记得我就够了，最好逢年过节愿意给我寄点小礼物。”  
“放心吧老大！我们肯定会给你寄最好的礼物！”  
“......倒也不用那么急着想散伙后的事。”

“她不是好人！”  
两个逃跑的女孩在荒野迷路，天色阴暗，难辨方向。  
“那个红头发疯子把我们从沙盗手里抢出来，就是为了再卖给其他沙盗！”  
阿雅吉和阿雅妮并非亲姐妹，而是被沙盗从不同地方抓来的奴隶，名字也是自己起的。  
“可她砍断了我们的脚镣，还给饭吃。”  
“演的！她老念叨什么部族的规矩，就是想让我们放松警惕。”  
“阿雅吉，我跑不动了！我想回去。跟着她起码不用挨饿。”  
“就算当沙盗，你也得认个有出息的老大吧？瞧她那样子，连个手下都没有，能有什么前途？”  
“可她说以前她有很多手下，只是那些人都不愿跟着她混了，她就决定再也不当老大了。”  
“那你怎么不想想那些人为什么不愿意跟着她混了？”  
她们只顾争吵，没注意到一群游荡的裂兽已悄然逼近了她们。  
“糟、糟了！阿雅吉，我不想死在这儿！”  
裂兽的族母绕着她们转圈，似在等待什么。其他裂兽朝远方咆哮起来。很快，一个红色的身影出现了。  
“我不是说了有裂兽出没，让你们别在我去买东西的时候乱跑吗？”  
“我还以为你在吓唬人，让我们不敢逃跑！”  
“逃跑？你们想走就走，我什么时候拦过？”  
娜仁图亚气喘吁吁地将皮鞭和匕首分给两人，随后上前，猎食者与猎物的游戏变成了两个族群间的对峙。  
“你要带着你的族群活下去，我也一样。她们是我的人。我们会反抗，我会杀死你族群中的裂兽，三头，两头，我绝对能杀掉。如果你喜欢两败俱伤，咱们就这么干。”  
裂兽族母陷入沉默。  
“看来你觉得不划算？”娜仁图亚啐了一口，“那就滚！”  
被激怒的裂兽纷纷咆哮，娜仁图亚也扯嗓子仰天怒吼，回敬以自己的态度。  
直到所有裂兽收起獠牙，娜仁图亚才停下，她扔出一个刚买来的包裹，里面是兽群必需的盐。  
裂兽族母叼起盐包，带着族群退回荒原深处。  
“走吧，回家。”娜仁图亚嗓音发哑，“既然收了你们当手下，以后就得听我的话，不能乱跑了。”  
“你、你什么时候收我们当手下了？而且，你不是说再也不当老大了吗？”  
“没办法，我也不想当老大，但我总不能看着你们去死吧？你们要是不愿意，我可以把裂兽叫回来。”  
阿雅吉闭上了嘴。阿雅妮凑近说：“这个老大能吓走一群裂兽欸，将来肯定有出息。”  
阿雅吉叹了口气：“我们俩现在都欠她一条命，这可该怎么报答呀？总不能给她当一辈子手下吧？”  
“阿雅吉，这已经是她第二次救我们了，一辈子可能都不够的。”  
娜仁图亚头也没回地应道：“我不需要你们报答我，我也没那耐心给别人当一辈子老大！将来哪天咱们散伙，过上安稳日子了，只要你们还记得我就够了，最好逢年过节愿意给我寄点小礼物。”  
“放心吧老大！我们肯定会给你寄最好的礼物！”  
“......倒也不用那么急着想散伙后的事。”

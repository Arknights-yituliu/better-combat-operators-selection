| 分支信息 | |
| * <替身>是此分支干员拥有的“二阶段”能力。 * 初始处于<本体>形态，此形态下受到足以致命的伤害且未持有[不死](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")的情况下，干员会在一段切换动画后，切换为<替身>形态战斗，持续20秒（期间持有[阻回](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")）。部分机制也可以直接让干员切换为<替身>形态，或是拥有多种机制不同的<替身>形态。 * <替身>形态持续时间结束时干员会在一段切换动画后，切换回<本体>形态。 * 切换动画期间会清除自身一切Buff；切换途中重设自身生命至最大值，随后再次清除自身一切Buff（存疑）。 * 切换动画期间干员持有以下效果：[不死](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[无敌](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[阻回](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[禁疗](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[孤立](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[强制缴械](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[晕眩免疫](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[冻结免疫](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")，[沉睡免疫](/w/%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C "异常效果")。 * <本体>形态下，干员可以且优先攻击自身阻挡的单位（即使目标处于攻击范围外或为飞行单位）；<替身>形态下阻挡数最终×0（通常从切换至<替身>开始时持续至切换回非<替身>开始）。 | |
| 备注 | |
| * 与特性默认值不同，该干员的持有不死的情况下，**会**因受致命伤而切换为<替身> * 从<替身>切换回自身时，重置来源于[丰川祥子](/w/%E4%B8%B0%E5%B7%9D%E7%A5%A5%E5%AD%90 "丰川祥子")3技能的免死效果，令其视为尚未触发过 | |

祥子有点担心睦。  
在罗德岛上生活也有一段时间了，睦还是跟以前一样不太爱说话。虽然任务和练习还是在正常参与，不过几乎无法看到她跟其他干员的沟通和交流。  
睦是个不太擅长说出自己想法的人，希望她不会积攒太多压力。祥子这样想着，决定去看看睦的情况。  
祥子知道，睦喜欢在疗养庭院里面待着，种植一些蔬果，这是她一直以来的小小兴趣。  
果不其然，祥子来到庭院，发现了睦的身影。  
祥子也不知道自己在紧张什么，躲在了远处的角落里，她听到睦好像在跟人聊天。  
睦竟然会在这里跟大家说上话？祥子感到有点欣喜。  
根据隐约听到的内容，睦他们似乎正交流着泰拉的种植方法，植物的生长周期，疗养庭院的环境系统，干员的喜好情况等等。  
“真的如Lancet-2你所说，灌溉也有好多细节。”  
“没错......我可以帮小睦调整灌溉的细节，比如在水中加入一些矿物质成分，调整分量保证水的节约使用。”  
“谢谢你......”  
“但说不定我也会搞错，因为我只是按照我的认知进行操作，我也不知道结果会如何......”  
“干嘛啊怎么回事你们怎么就低落下去了！大家自信起来！我们肯定没问题的！”  
“控制光照就麻烦THRM-EX了。”  
“太感动了！请交给我吧！我第一次做这么细腻的工作！我一定完美完成，保证不爆炸！”  
“......请务必不要爆炸。”  
“......就这小打小闹为什么要把我叫过来，我还以为是疗养庭院改进工程需要我。我要离开这里。”  
“Friston-3先生请您也帮帮我。”  
“别，Castle-3你别推我，什么，让我特意杵在这里，是要我做护卫防止别人来偷蔬菜？？”  
“最后是我？小睦你是希望我能教你如何进行除虫和植物保养？呵呵，听起来很不错，偶尔帮助孩子们学习也挺好。”  
“我们分工合作，一定可以种出罗德岛最大的黄瓜来！到时候让可露希尔吓一跳！”  
“......小打小闹。浪费时间。”  
祥子欣慰地猜想，睦来到罗德岛后原来也认识了这么多朋友。  
但祥子没有听得很清楚，不确定睦这几个朋友的名字。有合适的机会的话，就问问睦这些新朋友到底是谁吧，祥子这样想着就离开了庭院。  
当然，睦成功种出了巨大的黄瓜，但是似乎因为动用了很多非常规种植手段导致果物的成分发生了不可测的变化而被禁止继续。睦从此闭口不谈这件事，祥子到最后也没弄清楚睦的新朋友们是谁。

在罗德岛上生活也有一段时间了，睦还是跟以前一样不太爱说话。虽然任务和练习还是在正常参与，不过几乎无法看到她跟其他干员的沟通和交流。  
睦是个不太擅长说出自己想法的人，希望她不会积攒太多压力。祥子这样想着，决定去看看睦的情况。  
祥子知道，睦喜欢在疗养庭院里面待着，种植一些蔬果，这是她一直以来的小小兴趣。  
果不其然，祥子来到庭院，发现了睦的身影。  
祥子也不知道自己在紧张什么，躲在了远处的角落里，她听到睦好像在跟人聊天。  
睦竟然会在这里跟大家说上话？祥子感到有点欣喜。  
根据隐约听到的内容，睦他们似乎正交流着泰拉的种植方法，植物的生长周期，疗养庭院的环境系统，干员的喜好情况等等。

祥子欣慰地猜想，睦来到罗德岛后原来也认识了这么多朋友。

当然，睦成功种出了巨大的黄瓜，但是似乎因为动用了很多非常规种植手段导致果物的成分发生了不可测的变化而被禁止继续。睦从此闭口不谈这件事，祥子到最后也没弄清楚睦的新朋友们是谁。

## 3. 现场约定（踩过的坑，直接照办）

- **回填分文件一律用 `_apply_batch.py`**（按表头定位列、以 HEAD 重建整行）：键＝干员名，同名多行写 `干员名（子表名）`（须与该表上方最近的小节标题匹配；`（2技能）` 这类非标题标签不会命中）；`--keep-prefix` 保留 `救急路径：`／`子 TAG：` 前缀——**若代理产出文本已自带该前缀，回填后会重复，须事后去重**（`^(救急路径：…；)(救急路径：…)` 与 `^\*\*…\*\*；` 两种形态都要处理）。
- **子 TAG 列与成员增删不由回填脚本管**；被移除行带走的 `文件:行号` 要登记 `strip_prts_noncombat.ACCEPTED`。
- **`audit_text_migration.ACCEPTED` 同名键必须合并**（令牌取并集、理由相接），批量登记后跑一次去重；**依据列只可加、不可改同一 token**（`文件.md:1,2` 与 `文件.md:1` 是两个 token，改写会报「依据丢失」——要整段保留旧 token 另起一段写新行号）。
- **两线呈现写法**：成绩块情形名＝模式名（`集成战略特限`／`生息演算特限`／`岁的界园志异特限`）或 `通用线`，特限排前；「最低可满足档」排最前；某线无贡献则只写贡献线＋说明。
- **倍率与面板解耦**：写数值前先问「这是倍率还是绝对值」——固定点数／召唤物伤害只进绝对值（总伤／DPS／每秒），倍率只写百分比结构。
- **派 TAG 改写类子代理**：用 `.claude/agents/tag-rewrite` 代理类型；产出写 `_out/*.json`（**顶层包 `{"Pnn": …}`**）；prompt 里点名「纯固定攻击的更高档不取」「两线呈现格式」「倍率解耦」三条，否则会被读反。
- 证据只进「依据」列；产物里不得出现范围代号、`S1/S2/S3`、模组档码、`表 2A`、`路径⑤`、分文件名。
- **回填会不会回退「依据」列**：`_apply_batch.py` 以 **HEAD** 重建整行（只替换条件／备注两格）——工作区若有与 HEAD 不同的「依据／编号／子 TAG」，回填即被回退。现实做法：动前先 `git status`／`git diff` 摸清既有差异并避开目标行，动后以 `audit_text_migration.py` 的「依据丢失 0」为准（曾经的 `_out/_cols_snap.py` 已不存在，勿再引用）。
- **P05（插拔容错）回填必须加 `--no-head`**：HEAD 的备注前缀是 `**救急路径：…**；`（带粗体），带回来会让 `generate_results` 的前缀正则解析不到、整批丢子 TAG；工作区才是当前态。仍配 `--keep-prefix`。
- **换行坑**：临时脚本写分文件一律 `p.write_bytes("\r\n".join(lines).encode("utf-8"))`——用 `write_text` 会因文本模式把 `\r\n` 再转义成 `\r\r\n`（每行后多一个空行），整张表解析崩掉，表现为 `generate_results --check` 报「荐『X』不是本 TAG 的成员」。发现后按 `b"\r\r\n" → b"\r\n"` 修回。
- **`ACCEPTED` 同名键必须合并**：字典字面量里重复键只有**最后一个**生效——批量登记走 `_out/_accepted.py`（它按键读旧值、**并集合并**后整体重写，天然去重；勿手工逐条塞重复键）。
- **审计默认只打印前 30 条**：登记放行表时用 `AUDIT_ALL=1` 让 `audit_text_migration.py` 全量输出（`_out/_accepted.py` 已内置：跑审计→按「键」合并登记→写回）。
- **块标签里的嵌套括号**：块标签形如 `第一天赋「X」（Y模组3级（HOK-Y），潜能5）` 时，标签校验必须按**配对**括号剥除（`generate_results._strip_brackets`）——用正则会漏掉嵌套、把含逗号的标签静默退回正文（表现为「块首疑似标签但未被识别」）。标签字数上限与 lint 阈值均为 `BLOCK_LABEL_MAX`（40）。
- **`_out/` 里的工具随手删不得**：`_out/_accepted.py`／`_cols_snap.py`／`_build_p13.py` 这类临时件是流程的一部分；清理前先确认后续批次不再需要。
- **模组代号补入脚本**（`_out/_sweep_codes_labels.py`）对**组合级 bullet**（12-阵容组合，会进 `read_combo_meta`）要按「每个提及点最近的在前干员名」解析（同名是子串时优先取更长的名字，如「归溟幽灵鲨」vs「幽灵鲨」）。
- **引用分词的全角冒号**：`strip_prts_noncombat.py` 的 `CITE_RE` 排除集须同时含 `：` 与 `:`；否则「X模组3级：塑心/塑心.md:162」的路径键会连同前缀一起被吞，任何在其前插入文字都会误报「失效」。
- **在引用紧前方改文字 → strip 审计「失效」误报（键名随散文变化）**：消除方式＝在该文件 `strip_prts_noncombat.ACCEPTED` 显式放行（按 `(分文件, HEAD 侧行号)`），注释写明「引用本身未变、仍指向同一处原文」（本轮 12 条即此类的范例）。
- **`_apply_batch.py` 读工作区用 `split("\r\n")`**：分文件若为 LF 行尾（13／04 历史上曾如此），回填会**静默 0 条**——动手前把目标文件规范为 CRLF（`"\r\n".join(...)`），回填后再照常。另：`_out/_accepted.py` 以文本模式读写 `audit_text_migration.py`，会把它转为 LF——功能无碍（autocrlf 归一化），但别再拿 `split("\r\n")` 直接读它。
- **`audit_text_migration.py` 的两处判定（本轮修正，勿回退）**：①成员表以「**其后紧跟分隔行**」判定——每张表各自判定，边界与排除记录等非成员表不再被沿用列头误读；②同名多行按**出现顺序配对**——同一干员追加新子表行时，旧行的校验对象不再被顶掉。
- **子代理的解释性读法要复核后落盘**：裁定原文可能只给判准（如真言「①按2层计，溢出1层算一层」）——写手可能读成「触发仍计 3 层」，须在回填前由主进程定读法并列入证伪清单（本轮真言按「触发只计 2 层、溢出层只转化弹射」落盘）。
- **scan-protocol 复核的实际形态**：写手 → 复核（证伪）→ 写手逐条修正 → 复验 → 核销；远距控制首批走了两轮（15＋6 项），修正清单本身就是交付物的一部分。
- **每批开发者回复原文必须归档**：回复写在**工作区**《待裁定.md》里（HEAD 侧常只有提问稿），折入后整文件被替换——若不先归档，今后任何复核都无法对照权威源（本轮终局复核即因此扣分）。做法：折入的同时把逐字回复留存到 `_out/待裁定-第N批-回复原文.md`（已建 `_out/待裁定-第七批-回复原文.md` 为首例）。

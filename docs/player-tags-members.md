- **条件**＝硬性达成条件（精英化、技能、专精、模组及等级、模式限定、目标限制）；精零 1 级即具备者写「无」。

- **召唤物/装置效果计入持有干员**；**模式限定模组（ISW-α / RA-α / SO-α 等）计入**，但必须在「条件」中写明、备注注明仅该模式可用（开发者 2026-09-10 口径）。
- 名单按**实装时间倒序**（同实装日按拼音序）；实装时间取自 PRTS `获得方式` 上线时间。打数/倍率等数值取专精 3（Rank Ⅲ）口径。**「阵容组合」的组合内成员与各「边界与排除记录」表按判定逻辑分组排列，不按时间序。**
- 判定均为机制层、时间无关（不收「新神/退环境」等当期强度结论）。

## 01｜决战歼灭

### 判定口径

- 规格原文：「类似维什戴尔3、玛恩纳3、银灰3、夏日威龙陈3等大范围高伤害打多的干员。」判定技能开启后的输出能力；保持**机制层、时间无关**的总原则，不写当期强度排名（数值比较只与同代际/同职业干员的结构对照）。
- 纳入须**同时满足**以下三条硬标准（专三 Rank Ⅲ 口径）：
  1. **持续时间较长**：长持续、大弹药量或可循环的大范围压制；排除「射一箭就没」的一次性/超短轴技能。
  2. **范围足够大**：以技能开启后的**最终有效攻击范围/覆盖方式**为主要判据——只要技能期最终覆盖大范围/多路/全图，或为等效大范围真群攻即可；**不要求技能文本写明「攻击范围扩大」**（如号角的要塞射程即为足够大的最终范围）。单点溅射半径（1.5~2.0 级）不作为排除标准（开发者已拍板：凯尔希·思衡托、司霆惊蛰、烛煌维持保留）。
  3. **DPS、总伤合格**：按 PRTS 数值（攻击力加成、倍率、目标数、攻击间隔、持续/弹药）估算，达到同代际「歼灭档」量级；DPS 与总伤任一明显偏低即不合格。
- 排除：纯对单/打数 <3；技能期最终覆盖仍局限于自身周围或阻挡目标（清杂/基石档）；纯控制、推拉、增益、治疗向；单体高倍率的「大C」另列边界清单。
- 召唤物/装置效果计入持有干员；**模式限定模组（ISW-α / RA-α）效果计入**，仅由该类模组提供的能力在「条件」写明模式限定、备注注明仅该模式可用。
- 数值一律取 PRTS 专精 3（Rank Ⅲ）原文；DPS/总伤为按 E2 满级面板（不含信赖/潜能）、专三倍率与攻击间隔的**估算值**，用于结构对照，非精确计算。打数/弹药在专精 3 才达标者在条件中标注。规格中的「夏日威龙陈」即假日威龙陈。

## 02｜拐杖

### 判定口径

- 依据 specify 原文：「类似白铁1、娜斯提3（仅限高台）、华法琳2、阿3、号角2天赋（仅限重装）等**有条件或无条件能够给其他干员直接增加攻击力或攻击速度**的干员」。
- **纳入**：通过天赋/技能/模组/召唤物/装置/光环，为**其他干员**（含目标包含自身的"自身和目标"类）直接增加**攻击力**或**攻击速度**；含"鼓舞"中提供攻击力的部分；含"拐亦是被拐者"型（如阿、能天使）。
- **排除**：脆弱/易伤（受伤提升，如塞雷娅钙质化、焰影苇草）、减防/削抗/法穿、纯技力回复（属「充电」）、纯生存保护（属「保人」）、部署费用/初始技力类、仅自身增益、对敌减攻速。
- **召唤物/装置效果计入持有干员**（白铁装置、娜斯提高台装置、掠风可靠电池）。
- **模式限定模组（ISW-α/RA-α 等）同样计入**，在条件中写明模式限定（见空弦）。
- 攻速"下限覆写"（不减但不加，如信仰搅拌机 X模3）暂不计入，见排除记录。
- **"攻击力提升至X%"（倍率型）**：若作用于**其他干员**且直接进入攻击力乘区，则收（如摆渡人「永志不忘」，利益方向是给队友增伤，体感等同拐）；其"不加算面板、逐次伤害判定"的机制写入备注。仅作用于自身的"提升至"不属本 TAG。
- 条件写法：目标限制（仅某职业/阵营/小队/状态/部署方向）、需在场上还是仅编入队伍、精英化、模组等级；数值口径统一标注（专三 / 7级 / E2）。

## 04｜充电

### 判定口径

- 纳入：**本干员机制**（本体 + 技能 + 天赋 + 模组 + 召唤物/装置）能够为**其他干员**回复技力、或加快其技力回复速度的干员（spec：「有条件或无条件能够为其他干员加快技力回复速度」）。硬性条件写入「条件」列（目标职业/技能类型限制、需在场上、精英化、模组等级、模式限定、触发方式）；数值与同类取最高规则写入「备注」。
- 模式限定模组（ISW-α / RA-α 等）**计入**（按开发者最新要求修正 §2.3）：因此获得充电能力的写入成员表，「条件」写明模式限定，「备注」注明仅该模式可用（异客 RA-α、空弦 ISW-α）。任务型限制（海蒂【破碎日冕】）按同一口径处理。
- 召唤物/装置效果计入持有干员（白铁 S2 装置、娜斯提 S2“监工专员”、掠风“可靠电池”）。
- 触发方式分四类（写入备注）：①持续光环型（铃兰/莫斯提马/白面鸮/黍/归溟幽灵鲨/海蒂）；②装置型（白铁/娜斯提/掠风）；③受击·攻击·治疗·击杀触发型（雷蛇/陈/瑕光/吽/华法琳/塞雷娅/夏栎/森西）；④部署·击杀·其他（推进之王/异客）。
- 排除：只对**自身**生效的（自身技力自然回复速度+X、攻击/受击/击杀回自身、X 模组“命中精英+1”、部署获得自身技力等）；只对**召唤物/装置**生效的；非技力资源（魔力等）且不能转化为他人技力的。
- 边界单列（未进主表）：只提供**初始技力**、仅**一次性**回复或概率极低、而不加快回复速度/不提供持续回复的（风笛、凛御银灰、荒芜拉普兰德、炎狱炎熔、新约能天使3、缪尔赛思 Y3、嵯峨/矩/罗小黑、遥 Y 模组）。**其中仅提供初始技力/部署时技力者已独立为「初动」TAG（见 `10-初动.md`），本 TAG 不再重复收录。**
- 数值取 PRTS 原文关键档位（7 级 / Rank Ⅲ）；技力光环类「同类效果取最高」须写明，避免与其它光环叠加误判。

specify 原文：「类似夜莺（法伤减免）、年3（物伤减免、阻挡增加）、纯烬艾雅法拉（元素损伤减免）、焰尾2（物理闪避）等能够为其他干员提供保护的干员。如果某个干员的保护能力有硬性条件，则写在条件里……对于具体保人的数值，写在备注里。」

- **纳入（对友方，含召唤物/装置来源）**：伤害减免（比例庇护/数值减伤/伤害转移承担）、防御力或法抗提升、闪避/抵挡给友方、屏障/护盾给友方、免死/锁血/不死给友方、元素损伤治疗·损伤减免·损伤屏障、抵抗（异常状态时间缩短）、嘲讽/吸引火力/为他人转移仇恨、使友方不被选为目标（迷彩类）、净化（解除友方异常状态）。

- **方向第一**：一切以 PRTS 原文主语/宾语为准（“使周围友方干员…”“治疗的目标获得…”为对友方；“自身获得…”为仅自身）。
- **召唤物/装置计入持有干员**（鸟笼幻影、机动盾牌、造型仪、防护单元、夜灯、质检/监工专员、机械水獭、诅咒娃娃等）；**模式限定模组（ISW-α/RA-α）同样计入**，条件中注明模式限定、备注注明仅该模式可用（如 归溟幽灵鲨 ISW-α3）。

## 06｜远程消耗

### 判定口径

- 依据 `docs/player-tags-specify.md`：「远程消耗：类似荒芜拉普兰德3、澄闪3、安比尔2等。如果某个干员的远程能力有硬性条件，则写在条件里……对于打数和特殊效果，写在备注里」。
- **纳入标准（两类，均要求 PRTS 原文明确写出"越界"或"全场"）**：
  - **A 打击范围越界**：技能/天赋/模组使自身攻击（含浮游单元、光束、锁定弹道）可打到自身**常规攻击范围之外**的广阔区域——原文出现「整个战场」「全场」「无限长的直线」「可以攻击到范围外被阻挡的敌方单位」等表述，且为**持续/永续/可反复**的消耗手段。
  - **B 全场持续伤害**：天赋/模组使敌人在**全场范围**持续受到伤害（每秒/每0.5秒结算），不依赖自身射程。
- **排除标准**：① 射程只比常规略远（攻击范围+1~2格、攻击距离+1、改为前方固定格数）或仅"攻击范围扩大"而无越界文本；② 以一次性爆发/单次触发为主而非持续消耗；③ 纯控制、纯减益（脆弱/攻速-）、纯增益、纯治疗；④ 自身增益（全场有敌人XX时自身攻击力+）。
- **模式限定模组（ISW-α / RA-α 等）计入**（开发者最新口径）：因此获得的远程消耗能力写入主表，条件注明模式限定，备注注明仅该模式可用。
- **召唤物/装置效果计入干员**；浮游单元等特性单位视为干员本体打击手段。**远程部署型召唤物**（打字机/无人机/陷阱等）单独列「纳入存疑」，见待确认第 2 条。
- 条件写硬性前提（精英化、技能、专精档位、模组及等级、目标限制）；备注写射程表述、打数、每秒伤害/倍率、附带效果（减速/停顿/恐惧/晕眩）、持续与消耗、特殊索敌与限制。
- **范围量化边界**：本仓库 PRTS 数据**不包含攻击范围网格**（抓取器注释见仓库根 `crawl_prts.py:65`——"攻击范围以彩色表格单元格绘制、无文本"），故"超远程"只能以原文表述划界，无法用格数落线；分支射程类（攻城手等）单列存疑，见待确认第 1 条。

## 07｜插拔容错

### 判定口径

- **specify 原文**：「插拔容错：类似缄默德克萨斯、麒麟R夜刀、耀骑士临光2等。如果某个干员的救急能力有硬性条件，则写在条件里，例如耀骑士临光需要精英化1。对于救急的类型，写在备注里，例如耀骑士临光为单切，缄默德克萨斯3为群控等。」
- **纳入（两条路径，满足其一即可）**：
  - ① **低再部署循环**：基础再部署 ≤25s（处决者 18s / 弑君者 22s / 行商 25s），或自带天赋/模组使再部署大幅缩短并达到可循环水平（伊内丝/晓歌 AGE-Y「首次撤退再部署-35%」≈23s、麒麟R夜刀 Y模「首次撤退再部署为 0」、艾丽妮 ISW-α「-60%」≈28s、佩佩 RA-α「-90%」≈7s），运作方式是「部署→放技能/打一套→撤退→再部署」。
  - ② **部署即生效的救场/容错**：不占用部署位（耀骑士临光 S2、12 名支援机械）、落地点火（0 技力「部署后」技能）、或撤退有收益（艾拉撤退引爆、琳琅诗怀雅 ISW 加速他人再部署）。
- **条件**：技能开放所需的精英化/专精、达成再部署或效果所需的模组等级；模式限定模组（ISW-α / RA-α）**必须写入条件**，备注注明仅该模式可用（依据 `_brief.md` §2.3 最新口径）。
- **排除**：仅有「落地自 buff」而无救急职能、技能需长技力暖机、再部署 ≥40s 且无落地即生效手段、召唤物/装置才具备低再部署而本体与装置均无救急定位者，详见「边界与排除记录」。
- 再部署数值取 PRTS 属性表与 deterministic.json `main.redeploy`；技能数值取专三（Rank Ⅲ）。

## 08｜大力推拉

### 判定口径

- 纳入：干员**可达成「大力」及以上失衡力度**的推/拉/拖拽/击退/弹开类位移（本体技能、天赋、模组、召唤物/装置均计入，召唤物技能归其持有者）。力度以 PRTS 技能原文为准，档位为 小力 < 中等力度 < 较大力 < 大力（原文未出现"巨力"技能描述，仅山的天赋名"巨力重拳"含此二字，非力度档）。
- **+1 级效果计入**：原文"力度提升一个等级""推力增加一级"类效果按提升后的档位判定，但必须把触发条件写入「条件」（如 温蒂 Y 模组的"阻挡≥2名敌人时"+1、雪雉天赋的"仅【感染生物】"+1、歌蕾蒂娅 Y 模组的"目标距离>2.5格"+1）。
- **模式限定模组（ISW-α / RA-α 等）计入**（开发者最新口径）：因此达成大力的写入成员表，条件注明"仅集成战略/生息演算"，备注注明模式限定。
- 边界处理：只达**较大力 / 中等力度**的进「边界与排除记录」单列，供开发者确认是否放宽门槛；只达小力及以下的、以及传送/诱导/缚地/失重/浮空等非失衡位移机制，明确排除。
- 条件写硬性前提（精英化、技能、专精档位、模组及等级、目标限制）；备注写力度档位、方向（推开/拉向/双向/径向）、可否对空、距离/半径、伤害与附加效果（晕眩/停顿/真实伤害/移动创伤等）、特殊用法（如温蒂3双大力推叠加）。

## 09｜阻挡数>=5

### 判定口径

- 纳入：**本干员自身机制**（本体 + 技能 + 天赋 + 模组 + 召唤物/装置）能够使**某一个实体**的有效阻挡数达到 ≥5 的干员。有效阻挡数 = 本体阻挡（含"已计入基础数值"的模组加成）+ 技能/天赋/模组加成；召唤物按其自身有效阻挡数判定（如迷狂牢笼"阻挡生成/刷新时本格所有敌人"按任务定义视为满足）。
- 模式限定模组（ISW-α / RA-α 等）**计入**（按开发者最新要求修正 §2.3 后口径）：因此使阻挡数达 ≥5 的，写入成员表并在「条件」中写明模式限定。
- 需按"最大可达阻挡数"判定，写清每个加成来源：精英化、技能、模组及等级；阻挡数不在专精档位变化的不写专精要求。
- 排除：只提高**友方**阻挡的（年 3 技能、海蒂、帕拉斯、娜斯提、风絮、执旗手系模组等）；自身加成后仍 <5 的；**多个独立实体的阻挡数相加**（如本体+召唤物各挡各的，不能算某一实体阻挡≥5）——后者中的争议案例进「边界与排除记录 / 待确认」。
- 备注只写数值 / 隐藏机制 / 特殊用法；不写"不占部署位"类玩家直觉。

## 10｜阵容组合

### 判定口径

1. **记录单元 = 组合（阵营/小队）**，不按单个干员平铺；同一干员可出现在多个组合。每个组合下逐个列参与联动的干员，并区分「提供者 / 受益者 / 计数成员」。
2. **纳入标准**：存在游戏内真实的编队/阵营/小队联动文本——「编入队伍时」「编队中有 N 名【X】干员」「场上每有一名【X】干员」「所有【X】干员获得加成」「【X】干员获得加成效果翻倍」等；天赋、模组、技能、召唤物文本均可，召唤物效果计入持有干员。
3. **排除标准**：仅势力相同但天赋/模组/技能无联动文本的干员不收（如 企鹅物流、黑钢国际、使徒、汐斯塔、莱塔尼亚、哥伦比亚、巴别塔、喀兰贸易、S.W.E.E.P. 等全库 0 条战斗联动文本；彩虹小队/行动预备组等只有基建技能）；「自身获得」而不是「为组合提供」的文本不收（本 TAG 关注的是组合整体增幅）。
4. **职业/类型联动另列 B 类**：官方 D-编队/阵营联动增益 22 人锚名单中，风笛、黑、年、苏苏洛、凛冬、德克萨斯、银灰、贾维 8 人的联动对象是「职业/初始费用/全队/支援机械」而非阵营，单列 §B 并标注建议与「拐杖/充电」TAG 去重（口径见待开发者确认 #1）。
5. **条件写硬性达成**：精英化、模组名与等级、编队/上场要求、编队人数（岁=4、莱欧斯小队=4）、是否模式限定；**备注写该干员自己提供的那部分加成**（数值取 PRTS 原文，标注专三/Rank Ⅲ 口径）及组合整体关键机制。

### 数据结构建议（供 results JSON 设计参考）

单列 `combos` 表 + `combo_members` 关系表（TAG×干员为多对多，组合×干员亦为多对多）：

```json
{
  "combos": [
    {
      "id": "combo_deepsea",
      "name": "深海猎人",
      "type": "faction",                 // faction | squad | class | conditional
      "trigger": {
        "scope": "squad",                // squad=编入队伍即生效 / field=需在场上 / either
        "min_members": 1,                // 岁=4、莱欧斯小队=4、深海猎人=1、卡西米尔=1
        "requires": ["精英2"],           // 硬性条件（精英化/模组/技能/携带）
        "mode": null                     // "ISW" | "RA" | "SO" | null（模式限定）
      },
      "mechanism": "多条天赋独立叠加（攻击/攻速/生命/回复/增伤/充能），来源互不冲突",
      "notes": "浊心斯卡蒂为【阿戈尔】，不吃深海增益，仅自身天赋被深海触发"
    }
  ],
  "combo_members": [
    {
      "combo_id": "combo_deepsea",
      "operator": "乌尔比安",
      "role": "provider",                // provider | beneficiary | counter | trigger_source
      "condition": "精英2（第二天赋）；需在场上",
      "remark": "击倒敌人时自身生命上限+120/攻击+30（最多9层），其他【深海猎人】获得50%效果且层数同步",
      "evidence": "乌尔比安/乌尔比安.md:63,65"
    }
  ]
}
```

- 建议 `role` 区分 `provider`（提供加成，进筛选主名单）、`beneficiary`（仅受益，可作组合内推荐位）、`counter`（仅为编队计数/触发条件存在，如岁的其余 6 人、莱欧斯小队其余 3 人）。
- 组合排序按「首个成员实装时间」倒序即可；`trigger.min_members` 是 UI 提示「还差几人成队」的关键字段。
- 同一干员可出现在多个组合（如 缇缇：米诺斯/萨尔贡；浊心斯卡蒂：深海触发源）。

### 插拔容错

1. **「70s本体+落地即生效」是否放宽纳入（本 TAG 最大不确定点）**。艾拉（地雷不占位+撤退引爆）、望（棋子3秒再部署）、黑键、玛露西尔、蕾缪安、赤刃明霄陈、斩业星熊等「插拔循环成立但再部署不短」。处理A：维持现状（仅收≤25s、自减再部署、不占部署位三类）；处理B：放宽为「任何落地即生效的救急技」。请裁决。
2. **12名「不占用部署位」支援机械是否全部保留在主表**。其满足「不占部署位+部署后生效」，但200s再部署、一场只能用一次（与耀骑士临光2同类，均无再部署循环）。若认为 TAG 必须含「循环」，建议整组移入边界或另设「一次性安全带」子类。
3. **自减再部署但循环仍≥40s者（四月42s / 斯卡蒂40s / 焰狐龙梓兰55s）是否保留在主表**。三者均为0技力落地技+天赋/模组减再部署，与18s快活在体验上差距明显，请确认取舍。

5. **情报官35s（谜图/齐尔查克/寻澜/冬时）是否因职业定位放宽**；伊内丝/晓歌是凭 AGE-Y 模组达到≈23s 才进主表，若「35s+落地回费」也算，则应补入这4人。

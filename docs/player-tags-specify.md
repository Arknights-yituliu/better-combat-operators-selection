常用的，会被纳入玩家玩法考虑的TAG，评定标准：战术方向泛用，或数值足够强。

TAG可以有子TAG，用于区分同一TAG下的实现方式、数值类型、生效范围等（例如“拐杖”的加算型/倍率型、需在场上/编入队伍即可；“全场光环”的增伤/伤害/削弱）。子TAG之下还可再分组，两级嵌套，例如“拐杖”的增益类型 → 攻击力(加算)/攻击力(倍率)/攻击速度/易伤(脆弱)。子TAG同样可被筛选。一个干员可以同时属于多个TAG。

决战歼灭
类似维什戴尔3、玛恩纳3、银灰3、夏日威龙陈3等大范围高伤害打多的干员

拐杖
类似白铁1、娜斯提3（仅限高台）、华法琳2、阿3、号角天赋（仅限重装）等有条件或无条件能够给其他干员直接增加攻击力或攻击速度、或使敌人受到的伤害提升（脆弱/易伤，如铃兰第二天赋「画地为牢」、灵知第一天赋「坚冰」）的干员。如果某个干员的输出加成有硬性条件，则写在条件里，例如号角天赋（第一天赋「军事要塞」）只对重装生效，且需要在场，精英化2；对于具体拐的数值和持续时间，写在备注里，例如白铁1技能最高提供96%攻击力加成，持续20秒。

充电
类似白铁2、娜斯提2、华法琳天赋、铃兰1天赋（仅限辅助）、莫斯提马天赋（仅限术师）、陈天赋（仅限攻回/受回）等有条件或无条件能够为其他干员加快技力回复速度、或为其他干员补充弹药（子TAG“补弹”，如信仰搅拌机）的干员。如果某个干员的技力回复加成有硬性条件，则写在条件里，例如铃兰天赋只对辅助生效，且需要在场，精英化1，如需要攻击力加成需要开启X模组至少2级；对于具体充电的数值和持续时间，写在备注里，例如铃兰1天赋提供+0.4/秒（同类效果取最高）技力自然回复速度，攻击力+9%，在场时持续提供。

保人
类似夜莺（法伤减免）、年3（物伤减免、阻挡增加）、纯烬艾雅法拉（元素损伤减免）、焰尾2（物理闪避）等能够为其他干员提供保护的干员。如果某个干员的保护能力有硬性条件，则写在条件里，例如年3需要精英化2。对于具体保人的数值，写在备注里，例如年为周围其他友方干员的防御力+80%，阻挡数+1。

远程消耗
类似荒芜拉普兰德3、澄闪3、安比尔2等。如果某个干员的远程能力有硬性条件，则写在条件里，例如荒芜拉普兰德3需要精英化2。对于打数和特殊效果，写在备注里，例如荒芜拉普兰德3的浮游单元最多可以同时攻击4个目标，并让浮游单元周围敌人移动速度-30%，每秒受到相当于攻击力100%的法术伤害（不叠加）。

插拔容错
类似缄默德克萨斯、麒麟R夜刀、耀骑士临光2等。如果某个干员的救急能力有硬性条件，则写在条件里，例如耀骑士临光需要精英化1。对于救急的类型，写在备注里，例如耀骑士临光为单切，缄默德克萨斯3为群控等。

大力推拉
例如温蒂3。如果某个干员的推拉力度数值有硬性条件，则写在条件里，例如温蒂3需要精英化2且3技能专精等级3。对于特殊使用方式，写在备注里，例如温蒂3可以配合其召唤物工程蓄水炮打出一波双大力推，让推出的效果叠加。

阻挡数5
例如年2技能Y模组，百炼嘉维尔3技能、酒神3技能（迷狂牢笼可以阻挡本格内所有可阻挡的敌人）等。对于达成此阻挡数有明确硬性条件的干员，写在条件里，例如年需要精英化2且开启Y模组至少等级1；对于需要特别说明的部分，写在备注里，例如酒神本身并不能阻挡>=5数量的敌人，但是3技能生成的迷狂牢笼可以阻挡本格内所有可阻挡的敌人，完全满足阻挡数>=5的条件。

阵容组合
这个TAG比较特殊，因为它不是单个干员就可以发挥全部实力的，而是需要阵容内的多个干员配合使用才能发挥最大效果。数据结构见 `docs/output-standard.md` §4.2（本 TAG 的成员即「组合条目」）。
例如，深海猎人（多名深海猎人的模组加成增幅可叠加）、黍2天赋（天有四时）、怒潮凛冬2天赋&早露2天赋（乌萨斯学生自治团）等。如果阵容增幅有硬性条件，则写在条件里，例如深海猎人需要开启各自的模组、精英化2以解锁2天赋等等。对于自己能够提供的那部分加成，写在备注里，例如怒潮凛冬的2天赋为技能期间所有场上干员攻击力和防御力+14%，【乌萨斯学生自治团】干员获得加成效果翻倍。

初动增加
类似风笛、凛御银灰等一众可使干员初始技力增加的干员；本TAG只收为其他干员在开局/部署时点增加初始技力者，触发式回复技力（击杀触发、概率触发、治疗触发等）归“充电”。如果某个干员的初动增加能力有硬性条件，则写在条件里，例如仅对某职业/阵营生效、风雪之眼左侧的干员、再部署时间最长的地面干员等；对于增加技力的方式（编入队伍/部署时）与具体增加多少技力，写在备注里。

抗削弱
类似信仰搅拌机X模组3级（使场上所有【拉特兰】干员的攻击速度不会低于战斗开始时的攻击速度）、可露希尔2天赋（降低部署费用下限，可透支部署）等能够保“局内默认机制下限”和提高“局内默认机制上限”、或为其他干员提供负面状态防护（抵抗/净化）的干员。如果某个干员的保下限/提上限能力有硬性条件，则写在条件里；对于具体保护的机制与数值，写在备注里。子TAG区分：下限保护（攻速/费用/其他机制下限）、上限提高（弹药上限、技力上限等）、负面状态防护（抵抗/净化，如灵知第二天赋给【谢拉格】干员的抵抗、流明技能对异常状态的解除）。
（本节 TAG 已转为官方设定 TAG，规格与名单见 `docs/official-tags-members.md` C 类「抗削弱」；本节保留为历史规格。）

次数对策
针对“次数类”敌人（需要多次受击才会被击破或触发机制的敌人）的干员，分为2个子TAG：
多段伤害：单个攻击动作造成3次及以上伤害的干员，例如维什戴尔2技能；攻击间隔（按实际攻速）须在2秒以内，且单段伤害之间的间隔须在2帧（0.067秒）以内。
间隔伤害：以固定周期或短间隔周期性结算伤害的干员，包括dot伤害（例如伊桑1技能、阿斯卡纶1天赋）与短间隔伤害（例如灵知特限证章特性追加、安洁莉娜特限证章1天赋增强）；平均结算间隔须在1秒以内，最远可攻击距离不超过1.5格者须在0.5秒以内。
两子TAG共用的次数门槛：技能内对单个敌人 ≥50 次、对群体 ≥25 次；常驻效果（普通攻击、天赋/模组常驻、永续技能）按同等速率折算、不受时长限制，0技力被动技能按常规技能核算；触发式不计；独立结算的伤害源（每道电流、每枚棋子、每个召唤物/装置）分别计数后合计。
如果某个干员的次数类能力有硬性条件，则写在条件里；对于每次攻击的伤害次数、结算间隔与具体数值，写在备注里。

吃拐一轮秒
类似锏3、死芒3、焰狐龙梓兰2等一轮技能内打出极高爆发倍率的干员（子TAG“聚爆”），或类似能天使3、寒芒克洛丝2等一轮内打出大量攻击段数/次数的干员（子TAG“连射”）；满足任一子TAG即纳入，可以同时属于两个子TAG，与“决战歼灭”不互斥。
聚爆：伤害窗口不超过10秒，且对同一目标的累计总倍率 ≥2000%。
连射：满足以下任一——①物理伤害且技能期间单次攻击之间的间隔不超过0.2秒；②物理伤害且一轮技能打完对单个敌人 ≥80 段；③一轮攻击 ≥25 次且平均每次 ≥250%。
如果某个干员的一轮爆发有硬性条件，则写在条件里，例如赤刃明霄陈需要精英1并开启2技能、隐现需要驻场未满20秒（弹药14发）；对于达线的倍率、段数与伤害窗口，写在备注里，段数与次数按实际攻速折算并写明模组/天赋来源，例如能天使3技能计入天赋攻速后 15 秒约 110 段（开启 Y 模组为 115 段）的折算过程写在备注。

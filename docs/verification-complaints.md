# 干员机制校验吐槽录（兼：我的不确定清单）

> 编写：2026-09-09。本文是 `docs/official-tags-members.md` v2 与 `docs/mechanism-understanding.md` 的"幕后花絮"，记录在汇总、统计、辨别 431 名干员机制的过程中，那些需要反复验证、让我不确定、甚至当场困惑到想摔键盘的部分。
> 立场声明：以下吐槽对象包括旧文档、PRTS 文案、游戏官方措辞——以及我自己。

---

## 0. 先交代事故现场

任务是把 v1 的 TAG 表从"粗扫估计"变成"逐干员核对"。v1 本身是值得尊敬的——它至少建了框架。但它把 119 个提到"晕眩"的文件算成 119 个施加者、把示例随手写得像抽卡歪池：

- **斑点**被当作"护盾/伤害吸收"示例——人家天赋是给友方**物理闪避**。一个守护者，硬被写成了盾。
- **卡涅利安**被塞进"施加沉睡"示例——她全套技能文本翻烂了也找不到"沉睡"两个字，人家是停顿，蓄力变束缚。
- **迷狂牢笼**被吹成“阻挡数正无穷”——召唤物数据表白纸黑字：**属性表阻挡数 0**。它真正值得备注的是独立于阻挡数属性的特殊机制“**可以阻挡本格内所有可阻挡的敌人**”（玩家侧归入“阻挡数≥5”体感 TAG，见 docs/player-tags-specify.md），跟“正无穷”的关系约等于我跟亿万富翁的关系。

教训第一条：**粗扫的"文件命中数"只是检索上限，不是持有者人数**。这句话值得刻在 TAG 文档封面。

## 2. 词表战争：官方自己有两套字典

明日方舟的官方语言分裂成了两套：

**A 套：客户端异常表**。43 个异常效果 + 2 个组合 + 11 种抗性，冷静得像数据库注释："失衡不是异常效果，是状态机"。
**B 套：悬浮词条（术语释义）**。停顿/脆弱/屏障/护盾/鼓舞……是给玩家看的。

然后干员文案随机从两套里挑着用，有时还用第三套（旧时代的遗产）。于是出现了这些"同义词地狱"：

| 你以为的 | 实际的 |
|---|---|
| 沉默 | 文案偶尔写"失去特殊能力"（拉普兰德 2019 年就这么写，年 2021 年还在写，闪击 2023 年还在写） |
| 虚弱 | 老干员写"攻击力降低 15%"，新干员写"施加虚弱"——**同一个 Buff**，隔代不同名 |
| 脆弱 | 塞雷娅钙质化写"受到的法术伤害提升"，通篇没有"脆弱"俩字 |
| 护盾 | 泥岩/年/砾都是"护盾"——但砾的是"吸收 100% 生命衰减的**屏障**"，泥岩的是"每 9 秒 1 **层**护盾"，官方词条把两者分得明明白白，玩家分得稀里糊涂 |
| 灼烧 | 伊芙利特 S2"持续受到灼烧伤害"——是 DoT，**不是**灼燃损伤。v1 把她列进灼燃损伤示例，v1 错了 |
| 过载 | 号角技能里明晃晃写着"过载："，但词条定义的过载是"两段计量槽、走到一半触发额外效果"——号角那是弹药倾泻，**词不达意不是你的错，是我的错** |
| 沉睡 vs 小睡 | 缇缇 S2 备注原文："对友方的沉睡效果为施加**小睡而非沉睡**"——官方备注都学会教玩家做人了 |

这套"双字典"是校验里最大的精神损耗源。我被迫把"语义等同"的旧文案并进官方词条（慕斯/山/泡泡进虚弱、天火/慑砂进脆弱），并在文档里注明出处——这算是对历史债务的温柔。

## 3. 云记忆不可靠（含自嘲）

在逐行校验前，我的"常识"里有大量错误，全被数据打脸：

- 我以为**棘刺**施加神经损伤——他的"神经腐蚀"是中毒，神经损伤只出现在 Δ 模组的条件句里（目标得先被别人打爆条）。旧稿也是这么以为的。
- 我以为**伊芙利特**是灼燃损伤元老——她是灼烧 DoT 元老，灼燃损伤持有者其实是烛煌/余/波卜/温米/薇薇安娜。
- 我以为**银灰/山**能施加恐惧——恐惧 2024-07 才随妮芙实装，全库施加者 5 人：妮芙、荒芜拉普兰德、八幡海铃、结城理、虎狼丸。
- 我以为"快速复活"是那 9 人——数据说处决者 18s 七人 + 弑君者 22s + 行商 25s，**情报官 35s** 卡在尴尬位，夜刀即便靠天赋再砍 30 秒也够不着线。
- 我以为 THRM-EX 快活——他的特性是"不进行攻击，且不受部署数量限制，但**再部署时间极长**"，处决者职业壳子里住着一个自爆机器人。

结论：**所有关于机制的自信，都应以原文行为准**。这也是为什么每条 TAG 判定都要求引到"文件:行号"——不是为了审计别人，是为了审计我自己。

## 4. 数据清洗小剧场（技术债的挽歌）

- 干员"属性"表格是"再部署时间 | 70s | 初始部署费用 | 22→24"这种键值对排版，召唤物表格是"键 | | 值 | | | | 键 | | 值"的错位排版——解析器第一版把 `再部署时间` 解析成了 `初始部署费用`，bug 修了两轮才意识到 `str.replace` 静默失败比报错更阴险。
- 临时脚本里有个变量叫 `m`，既当"meta 字典"又当"月份循环变量"，运行到第 431 个干员时 Typeerror 教做人："'int' object does not support item assignment"。
- 模组区块是剧情、数值、材料图标的量子叠加态：一段"基础信息"后面可能跟着 40 行材料图标，然后是第二遍剧情（全文阅读/关闭全文双份）。摘要化的过滤规则写了三个版本，第三个版本才让"每帧检测"这种注记不再被剧情小说淹没。
- `docs/temp.txt` 曾是个 920KB 的 HTML 快照（现留作 0 字节空文件）——cat 它的人会得到一个教训。

（这部分不值得同情，纯属自找。）

## 5. 判定一致性的社会学：同一份文本，15 批标注员的战争

把 431 名干员分 15 批并行判定后，最大的发现是：**人类（哪怕是 AI 人类）对同一行文的理解并不一致**。跨批次出现了至少五次"系统性分歧"，每次都逼我写"归一化规则"：

1. **召唤物"部署占用数 0"算不算不占部署位？** 一半批次算，一半不算。最后裁定：不算——那是召唤物数据，不是干员特性；真正算数的只有 12 名"免费干员"文本 + 耀骑士临光 S2。
2. **"失去特殊能力"算不算沉默？** 新批次靠官方备注（年技能的备注直接写"沉默效果"）认了，老批次不敢认。最后按"官方沉默旧文案"统一收录 15 人，并留了复核开关。
3. **ISW-α/RA-α 模组（集成战略/生息演算限定）算不算数？** 安洁莉娜靠 ISW 模组能"浮空 3 秒"，凯尔希靠 ISW 模组"Mon3tr 不占部署位"——这些全在干员页里躺着，跟常规模组长得一模一样。最后**官方类**口径为**不计**（`docs/official-tags-members.md` §1 铁律⑤）；**玩家类**为**计入**、必须在「条件」写明模式限定（`_brief.md` §2.3）。**我至今不确定这是对的决定**。
4. **"每帧检测"算不算帧级结算？** 巫恋的天赋备注写着"血量百分比每帧检测一次"；珊比的传送带"每帧施加矢量"；麒麟R夜刀弹道"每帧判定一次攻击"。三者都每帧，为什么前一个是实现细节、后两个是真机制？因为前者是"阈值天赋的刷新频率"，后者是"结算载体本身"。这个区分标准是我编的，欢迎推翻。
5. **免疫 vs 持有**：召唤物信息栏"持有无敌、禁疗、晕眩免疫、沉默免疫……"把多个批次吓退——它们以为白铁的平台是免控战神。实际上那只是"不可被攻击的实体"的体检报告。裁定：实体固有属性不计入干员 TAG。

这场"战争"的直接产出是 `agent_workspace/tag_pipeline/` 里的归一化规则——**它们比 TAG 名单本身更值得保存**，因为下一批新干员上线时，同样的分歧会原样复发。

## 6. 我的不确定清单（每条都标注了去处，但都没闭嘴）

| # | 困惑 | 证据 | 我的处理 | 它为什么还烦我 |
|---|---|---|---|---|

## 7. 三个哲学问题（没有答案，但有立场）

1. **机制和数值的边界在哪？** 移速-60%（塞雷娅钙质化）和停顿-80% 只差 20%，一个没 TAG 一个有 TAG。立场：以官方词条为界，词条说它是停顿才是停顿；否则"减速"系迟早泛滥成灾。
2. **实现细节该不该成为玩家知识？** "每帧检测""0.1 秒后判定""1 帧后失效"在干员页备注里大量存在。立场：能改变手感/对策的（帧伤弹道）才配当机制，纯刷新频率（每帧检测血量阈值）只是工程文档。
3. **AI 批量标注长期该靠字典还是靠人？** 本次 15 路并行 + 归一化的结果证明：字典（catalog.json）能拦住 80% 的错误，剩下 20% 是需要人类拍板的"词条战争"——而且那 20% 恰好是玩家最常吵的部分。

## 8. 结语（半吐槽半诚恳）

如果让我用一句话总结这趟校验：

> **明日方舟的机制体系不是一座冰山，是三座冰山叠在一起——客户端异常表、玩家词条、干员旧文案，每层都有自己的命名规范，中间还夹着模式限定模组和实现注记。** 任何"我一眼就知道"的机制结论，都值得回去翻一眼原文行号。

好消息是，翻完 501 个文件之后，这份不确定性已经从"到处都有"收敛成了上面 14 条清单——它们都写清楚了证据、现状与出路。剩下的就是等开发者拍板，或者等下一个版本更新把其中几条直接作废。

（如果看到这里你觉得我在抱怨——是的，我在抱怨。但我把每一条抱怨都变成了文档里的一个备注。这大概就是数据人的浪漫。）

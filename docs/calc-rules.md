# 计算规则与因素匹配

> 本文收录本项目的**计算规则**：结算层位与总式、游戏文本到计算因素的映射、从面板到结果的演算流程，以及影响计算的未定项索引。
> 上游依据：PRTS 机制页快照 `material_datas/PRTS/_rules/`——`游戏数据基础.md`（伤害公式、攻速公式）、`作战机制.md`（伤害计算表、帧率）、`游戏数据基础／属性计算例子.md`（官方算例）、`属性.md`、`就近取整.md`；项目内成文见各 `material_datas/tag_pipeline/player_tags/NN-*.md` 的**计数方式**与 `_reverify/rules.md`。
> 边界：各 TAG 的**数值门槛**不在本文，见 `docs/player-tags-specify.md` 与各 `NN-*.md` 评定标准；游戏术语见 `docs/glossary.md`；「（待验证）」的标注范围见 `docs/concept.md:33`；逐条复算与并列记录见根目录 `待验证复算.md`。
> 维护：规则变动先改本文，再同步 `material_datas/tag_pipeline/player_tags/_reverify/rules.md`（复算作业副本）。未定项一律并列两侧，不静默取一套。
> **适用范围：本文的计算规则只作用于玩家体感 TAG**（`material_datas/tag_pipeline/player_tags/NN-*.md`）；**官方设定 TAG 不涉及计算部分**——其条目只写成员、条件与说明性备注，不做数值演算（`docs/rulings.md`「计算规则的适用范围」）。

## 1. 符号、结算层与总式

### 1.1 符号

| 符号 | 含义 | 出处 |
|---|---|---|
| `X₀` | 面板攻击力＝**满信赖 ＋ 最高精英化阶段满级 ＋ 有效潜能最高档 ＋ 条件点名模组档位的固定属性**（§4.1；复算工具 `prts_stats.py` 的 `panel_of()`） | `01-决战歼灭.md:21` |
| `a` | 直接加算项（固定值，如「攻击力+30」「攻击速度+8」） | `_rules/作战机制.md:404` |
| `b%` | 直接乘算项（百分比，同池相加） | `_rules/作战机制.md:405` |
| `c` | 最终加算项（绝对值，如鼓舞光环、对敌固定点数增伤） | `_rules/作战机制.md:406` |
| `d%` | 最终乘算因子（改写式，各自独立相乘） | `_rules/作战机制.md:407` |
| `s%` | 段倍率（技能/特性写明的「造成相当于攻击力 X% 的伤害」） | `_rules/游戏数据基础.md:900-958`（伤害公式） |
| `e` | 附加攻击力（伤害式中的固定附加项） | `_rules/游戏数据基础.md:900-958` |
| `T₀` | 理论攻击间隔（基础值，或被技能改写后的值） | `_rules/游戏数据基础.md:962-964` |
| `S` | 攻击速度（默认 100） | `_rules/游戏数据基础.md:975` |
| `T` | 实际攻击间隔 | `_rules/游戏数据基础.md:962` |
| `n` | 攻击次数 / 跳数 / 轮数 | `01-决战歼灭.md:18` |
| `m` | 倍率（伤害 ÷ 面板攻击力） | `01-决战歼灭.md:11` |
| `N_target` | 计入的目标数（默认 1） | `02-次数对策.md:7⑤` |

### 1.2 结算层与判据

| 层 | 公式 | 对应什么文本特征 | 判据 | 出处 |
|---|---|---|---|---|
| 直接加算 | `X₁ = X₀ + Σa` | 「攻击力+NN」「攻击速度+NN」等**固定值** | 给的是绝对值，不是百分比 | `_rules/作战机制.md:404`（阿「攻击速度+100」） |
| 直接乘算 | `X₂ = X₁ × (1 + Σb%)` | 「攻击力+X%」等 **X% 型提升** | 是「+X%」而非「提升至 X%」；**同池多个百分比相加后一次乘，不得连乘** | `_rules/作战机制.md:405`（黑「攻击力+180%」） |
| 最终加算 | `X₃ = X₂ + Σc` | 「额外加上（某单位）攻击力的 X%」类光环/鼓舞；对敌固定点数增伤 | 数值来源是**别的单位**的面板，或为固定点数 | `_rules/作战机制.md:406`（空）；`_rules/游戏数据基础／属性计算例子.md:51-58` |
| 最终乘算 | `X₄ = X₃ × Π d%` | 「提升至/提高至 X%」「造成伤害提升至 X%」及独立乘算因子 | 是改写式（值本身就是 d）；**该层多个因子独立相乘，不相加** | `_rules/作战机制.md:407`（推进之王「提高至380%」） |
| 最终效果·伤害乘算 | 百分比相加 | 「受到的伤害减少 X%」类减伤/易伤 | 官方在该行明写「百分比相加」，与上面四层算法不同 | `_rules/作战机制.md:413` |
| 最终效果·伤害重写 | 重写（按次数） | 「需要 N 次伤害击倒」类特殊生命值 | 伤害量被重写为计数，是「次数类敌人」的机制根源 | `_rules/作战机制.md:414` |

**计算前提·默认敌人**：一切倍率与伤害演算默认敌人为**纯木桩**——0 防御力、0 法术抗性、0 闪避／免伤概率、无其它任何减伤手段。据此：作用于**敌方防御／法术抗性数值**的效果（减防、降抗、无视防御／法抗、穿透）在该前提下**不产生增量、不计入**；作用于**承伤倍率**的效果（脆弱、通缉、「受到的伤害提高 X%」类）照常计入（§4.5）。

### 1.3 主式

```
间隔侧
  S = 100 + Σ（明文攻速来源）                        ← 攻速按直接加算（R2/R3）
  T = T₀ × 100 / clamp(S, 10, 600)                 ← 官方攻速公式

伤害侧（逐段，层位自内向外）
  X₀ = 面板攻击力（满信赖 ＋ 最高精英化阶段满级 ＋ 有效潜能最高档 ＋ 条件点名模组档位固定属性；§4.1）
  X₁ = X₀ + Σa                                      ← 直接加算
  X₂ = X₁ × (1 + Σb%)                               ← 直接乘算（同池相加）
  X₃ = X₂ + Σc                                      ← 最终加算
  X₄ = X₃ × Π d%                                    ← 最终乘算（独立相乘）
  A_seg = X₄ × s% + e                               ← 官方「基本伤害」式
  m_seg = A_seg ÷ X₀                                ← 倍率定义

合成
  总倍率 = Σ_seg ( m_seg × n_seg ) × N_target        ← 段数求和 × 目标数
```

`m_seg = A_seg ÷ X₀` 是「层位语言」与「倍率语言」之间的桥：层位描述属性怎么叠，倍率描述相对面板的产出；`X₀` 取面板（含信赖／潜能／模组档位固定属性）使**倍率数值不随这些固定加项变化**，只有面板数字与绝对伤害随之更新（§4.1）。

### 1.4 辅助式

```
间隔式     T = T₀ × 100 / clamp(S, 10, 600)；S = 100 + Σ攻速
次数式     n = round(持续 ÷ T)                       ← 四舍五入、含首击
段数式     段数 = Σ(每次攻击段数 × 攻击次数)
           每次攻击段数 = 命中数 × (1 + 每击附带段数)
跳数式     跳数 = 覆盖时长 ÷ 结算间隔（刷新式持续伤害取技能内覆盖时长）
窗口式     连斩/多段 = 段数 × 段间隔；周期性 = 跳数 × 跳间隔
           弹药制 = 弹药数 ÷ 每次消耗 × T；弹药倾泻 = 实际倾泻耗时
弹药式     轮数 = 弹药数 ÷ 每次消耗
期望式     期望次数 = 触发率 × 触发机会
过载分段式 时间型：[0, T_技能/2) 为前半、[T_技能/2, T_技能] 为后半
           弹药型：自第 (N/2 + 1) 枚起为后半（弹药剩余量降至一半时触发）
```

### 1.5 两条通用读法

1. **「层」与「链」不是一回事**。「层」回答**和谁相加**，「链」回答**乘进哪个量**。攻击速度按直接加算处理，但它不进 `X` 链，只进 `S`；「攻击力+X%」既在直接乘算层，又乘进 `X` 链。把攻速当乘算因子或乘进倍率，是结构性错误。
2. **改写式的修正规则**：最终乘算层的数值先修正——「提升至/提高至 X%」的 `d = X%`；「±X%」的 `d = 1 ± X%`（如 −40% → ×60%）。凡减益写成负数者，一律先加 1 再进 `d`（`_rules/游戏数据基础／属性计算例子.md:15,32`）。

### 1.6 官方算例对照

| 官方算例 | 算式 | 验证的层 | 出处 |
|---|---|---|---|
| 慕斯＋槐琥减攻 | `1000 × (1 − 40%) × 60% = 360` | 直接乘算与最终乘算分属两池 | `_rules/游戏数据基础／属性计算例子.md:34-36` |
| 真银斩被双重减攻 | `1000 × (1 − 40% + 200%) × 60% = 1560` | 「攻击力+200%」与「−40%」同池相加；最终乘算独立 | `_rules/游戏数据基础／属性计算例子.md:41` |
| 空为真银斩银灰加成 | `1000 × (1 + 200%) + 500 = 3500` | 最终加算位于直接乘算之后、最终乘算之前 | `_rules/游戏数据基础／属性计算例子.md:58` |
| 空＋双重减攻 | `(1000 × (1 − 40% + 200%) + 500) × 60% = 1860` | 四层顺序的完整串联 | `_rules/游戏数据基础／属性计算例子.md:62` |

## 2. 游戏文本 → 因素映射表

### 2.1 读法与列义

- 用法：拿到干员的特性/天赋/技能/模组原文后，按「游戏文本模式」一列逐句对号入座，得到该句的**因素类别**与**层位/计算位置**，再把全部因素装进 §1.3 的主式。
- 四张表按因素类别分组（攻击力与伤害量 / 攻速与间隔 / 段数次数与跳数 / 窗口弹药过载与条件）；「判定要点与常见坑」取自复算与因素审计的实际错例。
- 示例中的编号一律为 `文件:行号`（PRTS 相对路径）；涉及裁定结论的行在末列给出规则位置（§1–§4）。
- 行文中的「攻击力/攻速」等词指 PRTS 原文用词，不另行解释术语（术语以 `docs/glossary.md` 为准）。
- 各表行内序号（如 `C1`）仅为本表编号，不与其它编号体系混用；历史冲突号 C1–C10 已全部裁定、其规则折入 §1–§4。

### 3.2 各步细则

- **取整与量纲**：百分比保留到 0.1%、秒保留 2 位、× 保留 2 位；整数单位（下/发/段/枚/次/轮/跳）取整并给算式（`_reverify/rules.md:51`）。
- **计算式写法**：一律显式写取整步骤，形如 `15÷2.13≈7.04→7 下（四舍五入）`（`_reverify/rules.md:91`）。
- **取值定位**：技能数值取专精三（Rank Ⅲ）；属性／潜能／模组档位固定属性一律取自 `material_datas/tag_pipeline/stats.json`（由 `prts_stats.py` 从 PRTS 语料抽取，版式统一、不再手抄）；模组数值行为多字段连写、按内容切分（`_reverify/rules.md:56`）。
- **并列**：拿不准的不硬判——给出两套算法与各自结果并说明取舍依据。
- **成绩取满配档、只两种情形并列**：模组／潜能按「对本 TAG 有帮助的最高档」取用并把所选档写进条件（取档口径见 §4.1：按绝对贡献判、有特限证章者优先）；模组路线等多方案**取满配一条**，其余在 `计算` 里写清为何不取（撰写规则见 `docs/concept.md`「备注分块」）。
- **自查**：面板是否与条件声明的档位相符、模组档位是否取满、恒等式是否成立、该干员的天赋／模组／召唤物是否都被点到——跑 `verify_numbers.py`（对着 `stats.json` 复算，只报告不改数据）。

## 4. 其余规定

### 4.1 面板与阶段

- 面板攻击力＝**满信赖 ＋ 最高精英化阶段满级 ＋ 有效潜能最高档 ＋ 条件点名模组档位的固定属性（攻击+N）**；「精英化阶段满级」与「满信赖」为默认口径、**不写入条件**（信赖无阶段折减，`_rules/游戏数据基础.md:204`）。**「有效潜能最高档」的取法**：取「对**本 TAG 判据**有帮助的最高潜能档」，达到该档时含其以下各档的面板攻击加成；对本 TAG 无帮助者不取档、面板按 1 潜基准；同一干员不同 TAG 可依不同档。面板并入档位固定属性与潜能面板加成后**倍率数值不变**，仅面板数字与绝对伤害随之更新。
- **双档成绩（低阶段可满足者）**：条件的精英化要求低于精英2、且该 TAG 的成绩依赖面板（绝对伤害、固定点数折算出的倍率等）时，**分别计算「最低能满足 TAG 要求时的成绩」与「最高能满足要求时的成绩」**，并列在该条目备注开头。
- **模组与潜能的选档标准**：模组按「对**本 TAG** 有帮助的最高档」取用——某档开始对该 TAG 有帮助、更高档若对该 TAG 无新增帮助则不取该高档；并把所选档写进条件。**这里的「有帮助」按绝对值判**：看该档对本 TAG 所判能力（伤害、固定点数、段数、窗口等）的**绝对贡献**是否更大，不得因更高档会拉低比值、稀释均值或使成绩余量变小而改取低档；比值类判据按取用该档后的数值重新核验。**取线规则**：多条**通用模组**之间**平权**——各自按本 TAG 判据取最高有帮助档，取**成绩更高者**写进条目。持**特限证章**（模式限定模组：集成战略／生息演算／岁的界园志异特限）者，**通用线与特限线分别计算**、两条线的成绩与条件各自写全，**UI 分别展示、特限线优先展示**（细则见 `docs/ui-render-rules.md`）；**多个特限证章**时同模式取更高者、不同模式分别计算并按 PRTS 模组页自上而下的顺序展示。无特限证章者，默认其各模组的增伤条件均满足、取数值更高的一条，并把达成该更高值的硬性条件写进条件。潜能同理（按绝对贡献判，**不得因更高档拉低比值而改取低档**）：某潜级的加成对该 TAG 有帮助 → 计入计算并在**条件**写明「**潜能N**」；同一干员的不同 TAG 可依据不同潜能档；多个潜能档均对该 TAG 有帮助时取最高档；**干员默认即为 1 潜（基准），帮助效果在基准即具备时不写潜能档，条件只写 ≥2 的所需档**。潜能的面板攻击加成按上述口径**并入面板基准**。**能提升本 TAG 成绩的可变动项**（驻场层数、叠层、消耗量等）**一律取最高有效档**，并同样写入条件。
- 同一条件并列多个模组档时，取对本 TAG 有帮助的最高档并把该档写进条件（不得两档叠乘）。
- 技能数值取专精三 Rank Ⅲ（`03-吃拐一轮秒.md:10`）；属性表取值按表头定位列（`_reverify/rules.md:56`）。

### 4.2 攻速与间隔

- `实际间隔＝（基础间隔或技能改写后的间隔）× 100/(100＋总攻速)`；总攻速按加算（`01-决战歼灭.md:18`、`02-次数对策.md:7③`）。官方公式为 `T = T₀ ÷ (clamp(S,10,600) ÷ 100)`，两式等价（`_rules/游戏数据基础.md:960-979`）。**实际间隔以整数帧存在**：`帧数＝round(未量化秒值×30)`、`实际间隔＝帧数÷30`（显示最多 3 位小数；派生量不二次量化）。
- 攻速只计 PRTS 明文来源：特性/天赋/技能/模组（含模式限定与模组档位），并写明来源与数值；技能内逐步叠加者按逐次结算累计（`01-决战歼灭.md:18`、`02-次数对策.md:7③`）。
- 总攻速参与间隔计算时按 10~600 夹逼；攻击速度属性自身下限为 20（`_rules/游戏数据基础.md:976-977`、`_rules/属性.md:18`）。
- 帧率 30FPS；1 帧 ＝ 1/30 秒 ≈ 0.033 秒、2 帧 = 0.067 秒（`_rules/作战机制.md:1096`）。

### 4.3 取整与帧

- **帧长**：帧率 30FPS，1 帧＝1/30 秒≈**0.033** 秒、2 帧＝**0.067** 秒（3 位小数四舍五入）。
- 次数/段数 `n = round(持续 ÷ 实际间隔)`，四舍五入、含首击；`⌊⌋` 不采用（`01-决战歼灭.md:18`、`02-次数对策.md:7①`、`03-吃拐一轮秒.md:25`）；实际间隔一律取**整帧值**后再计数。
- 该约定是估算模型，与引擎的「就近取整（四舍六入五成双）」不等价；复算值的小数部分恰为 .5 时须在备注并列就近取整值（次数与帧数两层分别适用），不得静默取一套（`_rules/就近取整.md`）。
- 计算式显式写取整步骤；量纲与小数位随原值（`_reverify/rules.md:51,91`），整帧间隔最多 3 位小数。

### 4.4 计数与段数

- 周期结算跳数＝覆盖时长 ÷ 结算间隔，与次数同取整；刷新式持续伤害按技能内覆盖时长计（`03-吃拐一轮秒.md:15`、`02-次数对策.md:7①`）。
- 附加伤害实例计段；每次攻击段数＝命中数 ×（1＋每击附带段数）——该条为**强制项**，随每一击附带的独立实例一律计入（`02-次数对策.md:7①`、`03-吃拐一轮秒.md:23`）。
- 过载技能只覆盖**后半程**（前半程按常态数值）；**分段各半**——时间型按技能持续时间对半、弹药型按弹药总数对半（即自弹药剩余量降至一半起）；段数按前半程/后半程**各自的动作模型**计（范例：维什戴尔 2 技能——前半对单每次攻击 7 段＝1 正常＋3×2 余震、后半 4 连发对单 12 段）；概率触发按期望并写明算式。
- **帧伤**（伤害以帧为粒度产生者，如「移动创伤」每 2 帧按移动距离结算）按固定 **2 帧（0.067 秒）** 结算间隔计入次数；单次伤害随移动距离变化者，次数按结算次数计、备注写明「需处于位移状态、伤害按移动距离结算」。
- 攻击间隔、持续时长、窗口、段数基准、已计入的攻速来源等属**计数输入项**，不属乘区因子——因素审计只统计乘性/伤害性因素（见 §4.5）。
- 群攻×目标数仅在伤害可叠加于同一目标时乘算，否则按 1（`02-次数对策.md:7⑤`、`03-吃拐一轮秒.md:16,23`）。
- 概率触发按期望计，写明触发率与算式（`03-吃拐一轮秒.md:23`）。
- 独立结算的伤害源分别计数后合计（`02-次数对策.md:7⑥`）。
- 格数一律含自身格计，**统一按「自身格＝0、相邻＝1」**（含斜向、横竖斜同价）；「最远距离 N 格」即最多走 N 步（`02-次数对策.md:7⑦`）。
- 弹药倾泻速率：原文写明者从原文；未写明（「每隔？」）默认**每 2 帧发射 1 枚**；原文明说「一次性发动／发射全部」者按一瞬间结算（窗口≈0）。
- 弹药按「弹药数 ÷ 每次消耗」折算轮数；倾泻限原文写明者（`03-吃拐一轮秒.md:15,18`）。
- 窗口通用写法：15 秒窗口取输出最高的 15 秒；多阶段按最后一段结算完毕计；连斩型未给每击间隔按每击 ≤0.4 秒（`_reverify/rules.md:27`、`03-吃拐一轮秒.md:15`）。

### 4.5 因子计入的判定

- 召唤物/装置造成的伤害与触发计入持有干员；模式限定模组（ISW-α/RA-α/SO-α/SO-β 等）与模式限定天赋计入，条件写明模式、备注注明仅该模式可用（`03-吃拐一轮秒.md:10`、`05-插拔容错.md:20`）。
- **召唤物/装置的并入分情况**：**需其他干员配合才能造成伤害者不计**（如白铁「铁钳号·原型机」须由我方攻击充能）；**自身能够造成伤害者计入**——折算基准按**各自攻击力**，仅当技能原文明确写按持有者面板计算时（如机械师「造成机械师攻击力300%的物理伤害」）才归一到持有者面板。
- **开技瞬间族计入**：技能开启瞬间结算的一次性伤害（开技落雷、剑气、即时触发等）落点在窗口内者计入。
- 必生效的天赋/特性/模组乘算须计入，含**模组档位固定属性与潜能面板加成并入面板**（§4.1）与**对敌固定点数增伤**（如「受到的法术伤害提高150点」，对施加该次攻击本身亦生效）；条件成立才生效的档位以「写进条目前提」为计入依据，未写进者取下限；概率触发按期望（写明算式）。
- **条件性增伤一律计入**：需要自身处于某状态（在场时长、精力充沛、凝神、高生命值等）、目标处于某状态（处于元素爆发期间、剩余生命值越低伤害越高）或布阵／数量条件（范围内存在其他我方干员、周围 8 格每个友方+X%、范围内敌人越多伤害越高）才生效的增伤，一律折入计算——把达成条件写进「条件」、数值取该条件满足时的值（不逐条取下限或不折入）。
- 敌人按 §1.2 的**默认木桩**口径：作用于敌方防御／法术抗性数值的减益与穿透（减防、降抗、无视防御／法抗）无增量、不计入；作用于承伤倍率的增伤（脆弱、通缉、「受到的伤害提高 X%」）照常计入。
- **比值类判据的同额基线扣除**：以比值为判据者（如插拔容错「≥ 不开启技能时的 3 倍」），两个对照组中**等额出现、且不随技能开关变化的伤害项**（同额基线，如由攻击触发的天赋固定点数）**在两侧同时扣除**后再比——比值只反映技能自身的贡献；取更高档位不得因此压低比值，若某比值随档位上升而下降即按此修正（见 `docs/rulings.md`「比值类判据：同额基线两侧同时扣除」）。
- **倍率与面板解耦**：**倍率只由各伤害源自身的百分比结构决定**，不因攻击力（面板／阶段／潜能／模组固定属性）变动而变——**固定点数伤害不折算进倍率**（按绝对值计入总伤／每秒伤害并在「说明」标明）；**召唤物／装置按各自攻击力与各自倍率计**，并入「平均每次」等倍率口径时按面值相加、不做跨面板折算；**攻击力只影响总伤／DPS 这类精确值成绩**（见 `docs/rulings.md`「倍率与面板解耦」条）。
- **给「处于某状态的友方干员」的加成，持有者自身满足该状态时计入自身**（如「在场时，所有处于起飞状态的友方干员攻击力+18%」——持有者技能期间自身起飞，该 +18% 计入其攻击力；此时按乘算进 `b` 池，不并入面板）。
- **单木桩场景与随机索敌**：**非真群攻的干员**（含打单溅射、打多溅射，见 `docs/term-map.md`）的演算场景统一为**攻击范围内只有一个木桩敌人**——「随机索敌／随机目标」类的额外伤害因此**必然命中该唯一目标，按单个敌人算期望并计入**（**不再**按「不保证命中」不计）。**有多目标条件性增伤的干员**不受此限：照旧把前提写进「条件」并计入（本条只降低无此类增伤者的计算复杂度）。见 `docs/rulings.md`「单木桩场景与随机索敌」。
- **长效控制的等效剥夺时长**（子 TAG「长效控制」的判据）：`等效剥夺时长 ＝ 控制效果真正阻止敌人行动的时间`——有明文时长者按明文；需折算者按木桩敌人的行动设定（**攻击间隔 2.5 秒、可被阻挡、不计其无冷却的首击**）折成「被剥夺的攻击节拍数 × 2.5 秒」。例：酒神 3技能 迷狂牢笼——技能期间神经损伤持续爆发，麻痹层数与牢笼生命反复补充/重置，木桩敌人（攻击间隔 2.5 秒）整段技能期无法走出 ＝ **等效剥夺 30 秒**；判据为 **≥15 秒**。
- **固定点数伤害计入段数**：固定点数伤害除计入总伤／DPS 外，**若它构成独立的伤害实例（每次攻击附带／每秒结算一次），还要计入段数**（次数对策的等效每秒段数、连射的段数档）——与 §2.5 C3「附加伤害实例计段」一致。
- **同一次攻击的多段判定按整次攻击计 1 次**：天赋写「每次余震独立判定」而成绩按整次攻击结算时（如维什戴尔残影爆炸），按每次攻击触发 1 次计，并在「说明」里写明这条计数方式。
- 过载按后半程分段、时间/弹药各半（§2.5 D3）。
- 不可折算倍率的项：元素损伤值本身不计。**固定点数伤害（「每秒 X 点法术伤害」「受到的法术伤害提高 N 点」）与召唤物／装置的伤害都不折入倍率**——固定点数按绝对值（点数×跳数）计入总伤／每秒伤害；召唤物按各自攻击力与各自倍率的面值并入。倍率只由各伤害源自身的百分比结构决定，不因攻击力变动而变（见 `docs/rulings.md`「倍率与面板解耦」「固定点数伤害」）。

### 4.6 证据与写法纪律

- 一切数值落 `material_datas/PRTS/` 下的 `文件:行号`；行号逐页定位、不得跨页套用；优先复用条目「依据」列已有行号（`_reverify/rules.md:55`）。
- 不写过程语与模糊措辞；拿不准不硬判，给出两套算法（`_reverify/rules.md:49,50`）。
- 「（待验证）」的标注范围见 `docs/concept.md:33`；数值门槛的权威源见 `docs/player-tags-specify.md` 与各 `NN-*.md` 评定标准；术语以 `docs/glossary.md` 为准——三处均只作指针，不在本文重述。
- **产出文本自包含**：成员行条件/备注与工作产物不得互相引用——禁出现条目 id、其它分文件名、「见/另见/同上/同格 -N」类指称；重复内容各写全。豁免：`docs/` 规范指针与 PRTS `文件:行号` 证据位。

### 4.7 双情形呈现（溢出机制与附加提分）

- **溢出机制**：干员可通过溢出机制把一部分资源（如超上限的棋子/弹药）转化为 TAG 所需输出时，**分别计算两种情形**——「完全溢出」（超额资源按**一瞬间全部结算**计，不计窗口时间）与「完全不溢出」；两种情形的成绩都写进备注（例：望 的 S3 棋子超出上限者自动部署、即时触发）。
- **附加提分**：干员本体即满足 TAG 要求、而召唤物／装置／特勤等附加因素可进一步提高成绩时，备注写明两种成绩——**仅算满足 TAG 要求那部分能力**者、与把**能提高该 TAG 成绩的全部因素**计入者（例：机械师 的召唤物「结构性原理」）。
- **成绩前置**：同一干员在该 TAG 下有多情形成绩时，成绩列在**备注开头**（撰写规则见 `docs/concept.md`「结果展示」）。

### 4.8 成绩项（写入备注）

- **决战歼灭**：每条成员行备注给出该技能 **全技能持续时长的总伤**与**平均 DPS**（＝总伤 ÷ 全技能持续秒数）；入 TAG 的达标判定按技能期内**输出最高的连续 15 秒**，其窗口总倍率写入「计算」块。
- **次数对策**：每条成员行备注给出**等效每秒段数**（＝技能内总段数 ÷ 持续时间；常驻型按同等速率折算）。
- 成绩随面板变动者随面板口径（§4.1）与双档规则一并呈现；**段数／次数（跳数）口径的成绩不随面板变动，条目不写面板组成式与面板型潜能档**（依赖攻速／间隔／段数的来源照写）；推算值不再加「（待验证）」（§4.6）。

### 4.9 慢热：超额提升

- **判据**：先决条件＝**吃拐后必须加快**该干员达成其「额外提升」条件的速度（条件由击杀、固定时间、概率等与攻速／攻击力无关的因素决定者不收）；比重量＝`超额提升 ＝ 实际提升率 − 常规线性提升`。**常规线性提升**＝「加成多少、输出就多多少」的部分——攻速加成按**动作数之比**（含取整台阶；自加速型按吃拐后稳态（满层）的实际动作频率比取）、攻击力加成按 `1/(1+Σb*)`（Σb* 为窗口内伤害加权平均的攻击力百分比池）；**攻速侧（再 +100 攻速，超额_AS）与攻击力侧（再 +100% 攻击力，超额_ATK）分别计算**。
- **纳入阈值（按机制类型）**：**命中次数／叠层型**与**技能期内条件达成型**：`超额提升 ≥ +20%`。**元素损伤爆发型**：只纳入自身能造成元素损伤、且敌人处于元素损伤爆发期间时能额外造成元素伤害的干员；其超额提升＝**吃拐后爆发覆盖增量所带来的元素伤害增量 ÷ 无拐元素伤害合计**——增量＝`覆盖增量 ×（爆发自身每秒元素伤害 ＋ 吃拐后自身在爆发期内结算的元素伤害率）` ＋ `吃拐后多出的爆发整次点数`（一次性点数按整次计入、不摊成每秒；以每秒结算的爆发伤害按其每秒值计入），分母取无拐时的元素伤害合计；**该型阈值 ≥+20%**。
- **排除**：与敌方生命值挂钩的加伤（剩余生命比例阈值等）不算「额外提升」条件；以击杀／击倒数积累的加伤不收；**持续时间无限的技能**不收；有界层数池型（层数随攻击逐次消耗）不单列。
- **计入项**：固定点数伤害计入总伤／DPS——含**元素爆发的固定点数伤害**（灼燃 7000／神经 6000／侵蚀 5000 一类，按绝对值计入窗口总伤）；因攻速增加的攻击段数计入段数。
- **演算口径**：窗口＝一轮技能（或等效输出窗口）；按 30 FPS 整数帧逐人模拟元素损伤的累积与爆发时点（累积满 1000 触发爆发、爆发后清零、冷却内封顶）；木桩口径同 §4.5；窗口内动作数按**攻击时点逐击计**（首击 t＝0、其后每实际间隔一击、时点落在窗口内者计入）；每个候选的窗口、间隔、触发时点、爆发轮次与计段口径随计算表记录，供复算。

### 4.10 显示成绩的帧模型与用法分支（引用外部计算工具的框架）

- **适用范围**：外部计算工具（**ArkDPS**）与我方**交集**内、且有**绝对数值类成绩**的 TAG——决战歼灭（总伤／DPS／窗口倍率）、吃拐一轮秒（连射段数／次数、聚爆总倍率）、次数对策（段数／次数）、远程消耗（单次／每秒伤害）。**相对判据不重算**（慢热超额、比值类判据、距离、时长、控制时长）；**站点没有的干员／技能维持我方原口径**。
- **分工**：**我方**提供计算基础数据与条件——面板（满信赖＋最高精英满级＋**有效潜能最高档**＋条件点名模组档固定属性）、天赋／特性／模组乘区、条件性增伤、攻速来源、30FPS 折帧；**站点**提供**算法框架、帧模型、用法分支**。**不使用站点默认给的具体数值**（面板／潜能／条件均以我方为准）。
- **帧模型**：**可攻击时长、取整帧与帧级时点按站点公式实际含有的项**（动画帧、取整帧、阶段/有效时长等，如 `四舍五入(可攻击时长 ÷ 间隔)`；**前后摇仅在站点公式实际含有时才用**——现行 P01 五行均不含前后摇项）；**间隔按我方**（含我方计入的全部攻速来源与潜能）。
- **用法分支**：站点的「用法」（地形／弹药分配／关技时点／开技次数等）转为**多情形成绩块并列**，情形名采用站点分支名；**不在成绩／说明正文行内注明**——引用标识集中在详情卡片末尾（见「来源标注」）。
- **达标判定**：交集内**同源**（按本节口径重算）；站点没有的按原口径；两口径值不同时在「说明」注明差异来源。
- **来源标注**：结果 JSON 的成员对象与引用了站点的组合条目增加来源字段 `{model, url, author, parts, detail}`——`author`＝作者（**极夜星辰**）、`parts`＝本条引用的部分（帧模型与用法分支／组合公式与默认数据等）、`detail`＝该部分的详细说明（见 `docs/output-standard.md` §4.2）；消费端**仅在详情卡片末尾**展示一条「数据来源：ArkDPS（作者：极夜星辰 · 官网 ark-dps.com/zh/）｜引用部分：{parts}——{detail}」（模型名为高亮链接）；**成绩／说明正文不写引用**（引用描述集中在末尾，提升阅读美观性）。

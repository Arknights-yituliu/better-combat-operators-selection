# 明日方舟作战干员机制理解笔记

> 整理日期：2026-09-09。
> 范围：截至当日 PRTS 全量抓取（431 名干员 / 501 个文件）与官方《异常效果》《术语释义》页，经逐行校验后提炼的机制认知。与 `docs/official-tags-members.md` 配套阅读；文中的"成员 N 人"仅代表整理当日的规模，现行名单与计数一律以该文档 §4 为准。
> 目的：把散落在干员文案、官方词条与实现注记里的规则，整理成一套可复用的"机制世界观"，供后续分类、答疑与 UI 文案参考。

## 1. 三层模型：先分清"异常、词条、文案"在说谁

明日方舟的机制描述存在三个层次，混淆它们是大多数"看起来矛盾"的根源：

1. **客户端异常层（AbnormalFlag / Combo / 状态机）**：PRTS《异常效果》页整理的 43 个异常效果 + 2 个组合（沉睡、闭锁）+ 11 类抗性。它是**开关型二进制数据**：不存在持续时间与叠加，"获得 X 秒某异常"其实是获得一个携带该异常的 Buff。
2. **工具提示词条层（术语释义，id=ba.\*）**：游戏内悬浮词条，如停顿/脆弱/屏障/护盾/鼓舞/战栗/麻痹/诱导/起飞/迟钝/重伤……它们是"给玩家看的官方定义"，与异常层**不是一一对应**（寒冷、冻结是异常；停顿、脆弱只是 Buff 效果）。
3. **干员文案层**：各干员特性/天赋/技能/模组的实际文字。文案**大部分**使用词条术语，**小部分**使用旧时代措辞（如"失去特殊能力"=沉默），**偶尔**把实现注记（"每帧检测一次""实际为×××"）写进页面。

**推论**：判定机制时以"效果语义"为准、以"词条字面"为辅；两套官方词架起来以后，真正剩下的歧义比想象中少（详见"吐槽录"文档第 2 节）。

## 2. 对敌施加（控制类）的分类学

### 2.1 三大"阻止"族（官方有统一检定分组）

| 检定 | 包含异常 | 玩家直觉 |
|---|---|---|
| 阻止攻击/阻挡 | 晕眩、无法行动、浮空、冻结、麻痹震颤、缴械（持无敌时忽略）、强制缴械、小睡 | "打不出来" |
| 阻止能力 | 晕眩、无法行动、浮空、冻结、麻痹震颤、小睡 | "开不了技能" |
| 阻止移动 | 束缚、自缚、冻结、浮空 | "走不动" |

注意：**失衡不是异常效果**（是状态机），所以失衡"实际防住了攻击"也不属于阻止攻击族；**战栗**只防阻挡状态下的普攻，不属于这三族。理解这一点，就不会再问"为什么束缚能动的敌人缴械了还能跑"这类问题。

### 2.2 硬控 vs 软控 vs 位移的官方分界

- **硬控**：晕眩（全能封）、冻结（封攻封移，友方冻结还-15 法抗）、沉睡（+无敌+不可阻挡）、浮空（空中化+缴械）、小睡（角色类 DOZE，与沉睡互不识别）。
- **软控**：停顿（移速-80% 最终乘算）、束缚（只禁移动，可被攻击）、寒冷（攻速降、两两转冻结——友方寒冷与敌方寒冷是两套叠加逻辑）、失重（重量-1）、缚地（把飞行拉回地面，对地面单位无效）、迟钝（2026 新词：移速/攻速/施法速率等比降、可叠加）、战栗、麻痹（层数打断普攻）、恐惧（逃离，不可阻挡，对角色类无效）、诱导（自行走向目标点，不可阻挡）、虚弱（攻击力降）。
- **位移**：推/拉（失衡状态机 + 力度等级）、诱导（敌人自己走）、传送（直接挪格子，有专门的"被传送"异常与传送免疫）。三者玩家都叫"拉人"，机制上互不相同——这是圣聆初雪（诱导）、余/黍（传送）、暗索/崖心（拖拽）能共存于一张地图的原因。

### 2.3 施加方视角小结

施加控制的方式维度（写入结果 JSON 的 R1 备注）：天赋一次性 / 普攻概率 / 周期性光环 / 技能期间持续 / 技能期间间歇 / 区域驻留（陷阱/装置）。同一种状态，佩佩（间歇）、卡达（概率）、U-Official（一次性）各是一种玩法，但**不构成不同 TAG**——这是 v2 与 v1 在哲学上最大的坚持。

## 3. 伤害结算体系

### 3.1 伤害类型的谱系

- 物理 / 法术 → 常规双轨，受防御 / 法抗减免。
- **真实伤害**：无视防御与法抗（凯尔希 Mon3tr 链、玛恩纳 S3、耀骑士临光 S3 等）。
- **元素伤害**：独立于物法的第三伤害类型（本源术师系核心，"攻击造成元素伤害"写在分支特性里即算）。
- **弱点伤害**：伤害结算时按目标防御/法抗临时算"理论物伤/理论法伤"，自动转成更高的一方（结城理、赤刃明霄陈；P3R 敌人另有硬弱点）。**它是伤判类型选择机制，不是穿透**。
- 穿透（无视防御/法抗）：与弱点伤害同属"在伤害计算里改参数"，但机制不同——官方文档 B 类分列为「无视防御」「无视法术抗性」「弱点伤害」等 TAG（名单见 §4）。

### 3.2 元素损伤：一条独立的"血条战争"

元素损伤（神经/灼燃/凋亡/侵蚀/狂躁五系）不是伤害，是推"异常条"，累计满 1000 爆发。现行客户端**对敌/对我方角色使用两套爆发效果**——五系爆发数值表见 `docs/glossary.md`「元素相关」与 `docs/official-tags-members.md` §8.3（本文不再复述）。

老玩家记忆里的"神经爆发=眩晕 10 秒"只在**我方角色中招**时成立；对敌人早就是"6 千元素伤害糊脸+麻痹"了。所有 TAG 定义里的爆发数值均按现行版本（若未来版本回退需同步）。

**"伤害"与"损伤"是两套结算**：灼烧（伊芙利特/火哨，DoT 文案）≠ 灼燃损伤（烛煌/余/波卜/温米/薇薇安娜）；中毒（棘刺/蓝毒）、流血（奥斯塔）同样是"文案系 DoT"，没有官方词条却真实存在。

### 3.3 我方"易伤/减伤"四兄弟（同名陷阱高发区）

- **脆弱**：受到的伤害提升 → 脆弱/物理脆弱/法术脆弱/元素脆弱四词（焰影苇草的灼痕直接写"【法术脆弱】"）。
- **庇护**：受到的物理/法术伤害降低比例（官方词；嘉辛塔甚至给全队对空庇护）。
- **伤害减免**：受到的伤害降低**数值**（浊心斯卡蒂 Y 模组与 Friston-3 之间的特例同名词条）。
- **减防/减抗**：纯数值削弱，无词条，按本项目原则不设 TAG（但它们是物理/法术队的重要组件，需在备注层记录）。

### 3.4 施加型 DoT 的结算计时（尾击与首击）

- **施加型 DoT**（「使目标／使命中目标／使其…每秒（每 X 秒）受到…伤害，持续 N 秒」「重复命中只刷新持续时间」，效果挂在敌方单位上者）：首次结算在施加后**第 1 个结算间隔**，**持续时长末端的「尾击」计入**——跳数＝⌊覆盖时长 ÷ 结算间隔⌋（恰为整倍时即 时长÷间隔，如 12 秒@1 秒＝12 跳）；**若施加该状态的那一击本身无伤害**（技能除该状态外无伤害输出），**另计 1 次「首击」**（施加时立即结算一次；例：望 1 技能 6.5 秒＝6＋1＝7 跳）。
- **不套此计时**：技能/天赋/装置/召唤物自身按间隔直接造成的伤害（区域、光环、脉冲、场所伤害）与条件状态型伤害；帧伤（移动创伤）按 2 帧机制原文。
- 计数落库：`02-次数对策.json` 共同约定①、`docs/calc-rules.md` §1.4／§4.4 与表 C5／C6；台账 `docs/rulings.md`「八、DoT 跳数循环裁定」。

## 4. 自保与增益：屏障/护盾/闪避/抵挡/隐匿一族

### 4.1 数值防护的官方分类（v1 最常翻车处）

| 词 | 定义 | 持有者举例 |
|---|---|---|
| 屏障 | 吸收**一定数值**伤害（蓝条延伸） | 砾 S2（100% 生命衰减屏障）、林（琉璃壁）、斥罪、夜莺 |
| 护盾 | 每层抵挡**一次**伤害 | 年（3 层）、耀骑士临光 S2（2 层）、泥岩天赋（1 层+破裂回血）、火龙S黑角居合 |
| 物理护盾 | 每层挡一次物理伤害 | 鞭刃（给高阻挡友方近战） |
| 闪避 | 概率规避物理/法术伤害 | 伏击客分支 50% 双闪、守护者给友方闪避（**斑点**）、蒂比"预判闪避" |
| 无敌 | 不可选中+伤害归零 | 技能期间（陈绝影、锏 S3、赤刃明霄陈斩击） |
| 不死 | 生命重设不低于 1 | 锁血技能（幽灵鲨/史尔特尔）、一次免死（圣聆初雪/信仰搅拌机） |

判定规则：文本说"吸收 X 伤害/屏障值"→屏障；说"X 层护盾"→护盾；**说闪避才算闪避**——概率"抵挡下一次伤害"（雷蛇 S1）与"远程物理抵挡"（九色鹿/导火索）是不是闪避的同义词，官方没给词条，目前按"不同体系"挂起（见遗留清单）。

### 4.2 "藏起来"三兄弟：隐匿 / 迷彩 / 不可选中

- **隐匿**：不阻挡时不成为敌方攻击的目标（受反隐影响；被阻挡会现形）。
- **迷彩**：不阻挡时不成为敌方**普攻**的目标（防不了溅射，也受反隐影响）。
- **不可选中**：干脆无法被不同阵营选中（狮蝎的"隐匿的杀手"实为不可选中，词条陷阱第一名——它**不受反隐影响**，与玩家认知相反）。

反隐（官方名：隐匿免疫）能让迷彩失效；三者全被"反隐干员"克制——银灰/极境/伊内丝/双月/真言/电弧/号角/稀音/月禾/铅踝/凛御银灰等可按需让敌人"现出原形"（完整名单见官方 C 类「反隐（隐匿免疫）」）。

### 4.3 免疫三件套的递进关系（agent 判定的头号绞肉机）

- **免疫（抗性）**：异常无法生效、无法被检测，但不清除已携带异常的 Buff。
- **反制**：获得即**清除**对应异常 Buff，且期间禁止再添加。
- **强启**：佩佩式——无视晕眩/冻结直接开技能。

免疫≠持有：召唤物信息栏"持有无敌、禁疗、XX 免疫"只是它的**实体属性**（类似"这块石头不能被点选"），不是干员给它的增益；干员自持"强制缴械"（隐德来希开技能、渡桥战术点形态）是代价不是能力。分清这个，缴械类 TAG 才不会出现"47 个文件提到缴械 → 47 人施加缴械"的乌龙——真实结果：**0 人能对敌缴械**。

## 5. 部署、费用与再部署

- **部署位**：“不受部署数量限制”是“免费干员”（机器人/联动赠送）+ 耀骑士临光 S2 的专利；召唤物页的“部署占用数 0/1”是召唤物侧数据，别混进干员 TAG（**例外**：决战歼灭的「总部署位 ≤1」标准按本体＋承载物的部署占用数合计判定）。
- **费用**：回复费用（先锋职能：尖兵/冲锋手/执旗手 + 若干特种）、撤退返还、部署返还、击杀回复……归入官方 D 类「费用回复/返还」；永久减费（编队天赋）另算编队联动。
- **再部署**：处决者 18s（砾/红/傀影/槐琥/卡夫卡/缄默德克萨斯/麒麟R夜刀）、弑君者 22s、行商 25s（孑/老鲤/乌有/裁度/琳琅诗怀雅）构成"快活族"；情报官 35s 卡在"快"与"不快"之间（本稿不设，但欢迎开发者拍板）。
- **移动族**：官方"移动"术语=不退场、以当前血量在目标地块部署，本质是一次特殊撤退-再部署（清空技力、不累积再部署惩罚、可重复触发部署时效果）。机械师、凯尔希·思衡托（战术锚点）、赤刃明霄陈等 7 人。
- **待部署区（策士）**：2025 新分支，人在场上影响待部署区干员的费用与部署（凛御银灰/松桐）——费用经济战的下一形态。

## 6. 召唤物：一支被数据善待的军队

- 60 名干员持有 70 个召唤物（manifest 全量）；实体类型分默认（Mon3tr、令的龙、麦哲伦无人机等 34 个）、装置（地雷/炮台/牢笼等 29 个）、战术点/默认混合（渡桥/缪尔赛思/豆苗等 7 个）。
- **部署占用数**：经典召唤物（Mon3tr/无人机/令的龙/稀音摄影车）占用 1；新式"干员附带单位"占用 0。
- 召唤物也能有召唤物：Mon3tr（2026 干员化）的召唤物是"重构体"，而凯尔希的召唤物也叫 Mon3tr——同名词条连 wiki 都得靠括号消歧。
- 绑定（凯尔希的技能 2/3 与 Mon3tr 生死绑定）、退场返还（本能的召唤退场返还 1 个可部署位）、被击倒自动刷新（渡桥的樱桃三号 20 秒复活）是三条独立的召唤物经济学。

## 8. 干员行为学：分支特性即机制

一些机制不写在技能里，而是**分支特性的本体**：

- 通常不攻击：吟游者（回血光环）、阵法术师（防御姿态攒技能）、解放者（阻挡 0 但越站越强）、策士等 → 16 人。
- 起飞：巡空者（起飞后挡 2 飞行敌人）、守望者（飞行奶妈）、裂空炮手（起飞打空、落地群伤）等 9 人——"飞行干员"已从敌人专利变成我方体系（予愿安洁莉娜 S3 滑翔起飞把地面敌人浮空、飞行敌人缚地）。
- 持续攻击：丰川祥子/祐天寺若麦/菲亚梅塔等——弹道系可以"越盾打人"。
- 伏击客分支：50% 双闪 + 不容易被选 + 范围伤害，但拦截后会被打。
- 傀儡师分支：受致命伤切换<替身>（免死但失去常态输出，20 秒轮回）。
- 凝滞师分支：攻击自带短暂停顿 → 全分支计入"施加停顿"（这是分支文本说了算的典型案例）。

## 9. 时间感：机制是随版本"分层"的

按 TAG 首次实装时间线（见 `docs/official-tags-members.md` §5），明日方舟的机制史大致是：

- 2019 开服即满配：晕眩/停顿/束缚/沉睡/推拉/真实伤害/快速复活/召唤物/闪避/隐匿……控制类骨架全部就位。
- 2020–2021：护盾/迷彩/抵抗/弹药/蓄力/冻结（灵知 2021-12 才让"冻结"有第二位施加者，此前是陈独秀）。
- 2022：凋亡损伤（黑键）打开元素损伤系；免疫系（陈/锏/止颂等）成型。
- 2023–2024：灼燃/恐惧/诱导/传送/移动/过载/魔力/吟唱陆续登场——"控制"从时长战转向机制战。
- 2025–2026：迟钝/重伤新词条、策士/巡空者/守望者新分支、起飞体系、帧级结算体系补齐（矢量／弹道／移动创伤类机制集中登场）。

**给玩家的体感结论**：新干员不靠更高的数值赢，靠"官方多给你一张词条表"赢。

## 10. 判别原则速查（本项目反复使用）

1. 官方词条有名 → 以词条定义与文案语义双校；词条无名但语义清晰 → 按"稀有机制"收录并注明文案出处。
2. 免疫、反制、强启、自持是四种不同的事。
3. 施加方向（对敌/对友/对己）是 TAG 的第一属性；联动增伤（对处于 X 状态敌人伤害+X%）永远不是施加。
4. 分支特性、模组、召唤物都是干员能力的一部分；模式限定模组（ISW-α/RA-α）除外。
5. "每帧"两个字可以指真正的帧级结算（帧级判定：珊比传送带矢量、弹药倾泻、每帧触发技能；帧伤：龙之箭/夜刀弹道、移动创伤），也可以指阈值天赋的实现注记（巫恋/铃兰/佩德洛的"每帧检测"）——前者进 TAG，后者进备注。

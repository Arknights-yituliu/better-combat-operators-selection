## 3. 统一检查分类（判定控制性质时以本节为准）

- **阻止攻击**（8）：晕眩、无法行动、浮空、冻结、麻痹震颤、缴械（持有无敌时忽略）、强制缴械、小睡；**失衡**（状态机）与**战栗**不属此列。
- **阻止能力**（使用技能，6）：晕眩、无法行动、浮空、冻结、麻痹震颤、小睡。
- **阻止移动**（4）：束缚、自缚、冻结、浮空；晕眩／无法行动／麻痹震颤因切换状态机实际也无法移动，但不属此列。
- **无法选择类**（5）：隐匿、不可选中、无敌、塔不可选中、对地规避（另有部署保护／DISAPPEAR 状态机自动视为无法选择；迷彩不属于此类）。
- **无法被友方选择**：孤立；**无法被治疗选择**：禁疗／孤立。
- **可影响沉睡单位的伤害**：持有 `DAMAGE_CAN_HURT_SLEEPING_ENTITY` 者，在目标无敌时按其判定规则可无视无敌造成伤害。

## 4. 与「高档控制」硬控／软控的对应（依开发者定义）

开发者定义：**硬控**＝可使受影响敌方单位**移动速度至少-100%，且无法进行普通攻击、无法释放主动技能**者（例：晕眩、冻结、浮空）；**软控**＝其余异常状态与位移，「阻挡」亦计作软控。

按本表统一检查，同时落在「阻止攻击」与「阻止能力」两列的异常效果为：**晕眩、无法行动、浮空、冻结、麻痹震颤、小睡**（其中 浮空／冻结 另属「阻止移动」；晕眩／无法行动／麻痹震颤经状态机实际无法移动；小睡为角色类单位状态机）。据此：

| 异常效果 | 硬控 | 软控 | 说明 |
|---|---|---|---|
| 晕眩 | ✔ |  | 阻止攻击＋能力，敌人类无法移动 |
| 无法行动 | ✔ |  | 状态机 STUN，同晕眩（无增伤标记） |
| 冻结 | ✔ |  | 阻止攻击＋能力＋移动 |
